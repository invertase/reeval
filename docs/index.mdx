## Introduction

**reeval** is an open-source evaluation runner built for developer tools, including SDKs, CLIs, MCP servers, skills, and documentation.

It runs coding agents inside isolated sandboxes, then grades their output using assertions and LLM judgments. Run identical prompted tasks across a baseline and a variant (your change) to compare whether it improves or regresses pass rates, tokens, and time.

The evaluation is code, committed alongside the tool, skill, or doc you are changing. The result is reproducible evidence you can share in pull requests, docs, or release notes.

## How reeval works

Agents, environments, and attempts multiply into sandboxes, grading reads each workspace, and the results measure, compare, and analyze the run.

## How it runs

reeval runs on your machine, and each run leaves a record you can commit:

| Part | What reeval does |
|---|---|
| [Sandbox](/integrations/sandboxes) | Starts a fresh container for each attempt |
| [Secrets](/environments/secrets) | Keeps API keys on the host and adds them only on requests to their provider |
| [Records](/runs/recording) | Writes each run as JSON beside your code, so a pull request can diff against it |
