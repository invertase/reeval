---
title: Recipes
description: Complete, copyable solutions to common eval tasks, each with its files, command and real output.
---

Each recipe is one task end to end: a goal, the files, the command, the output and a few variations. Every eval and config on these pages was checked with `reeval run --dry-run`, and with the fake harness where it can run them.

```bash
npx reeval run --dry-run
```
