---
title: "Compare harnesses"
description: "Run one task on each agent and read each one's pass rate, tokens, tool calls, and time."
---

You compare agents by running one task on each agent in one run. Each agent is its own cell with the same prompt, assertions, and attempts, so the block reads side by side. For a runnable project, see [`with-many-harnesses`](https://github.com/invertase/reeval/tree/main/examples/with-many-harnesses). For more information about choosing an agent and its key, see [Choose an agent](/agents).

To measure a change on each agent instead, add `compare` ([Compare harnesses](/results/compare/lift#compare-harnesses)).

## Run one task on each agent

<Steps>
<Step title="Write the evaluation">

In the `evals/stream.eval.ts` file, list the agents in `harness` and give each one four attempts with `runs`:

```ts title="evals/stream.eval.ts"
import { evaluate, expect } from '{{ pkg }}'
import { claudeCode, codex, cursor } from '{{ pkg }}/harness'

evaluate(
  'streams with Vercel AI SDK',
  {
    harness: [
      cursor({ model: 'composer-2.5' }),
      claudeCode({ model: 'claude-sonnet-5' }),
      codex({ model: 'gpt-5.6-luna' }),
    ],
    runs: 4,
  },
  async (c) => {
    await c.send(
      'Add src/stream.ts with a streamChat(prompt) function that ' +
        'streams a reply with Vercel AI SDK.',
    )
    await expect(c, 'adds the ai package').toHaveFile('package.json', /"ai"/)
    await expect(c, 'uses streamText').toHaveFile(
      'src/stream.ts',
      /streamText\(/,
    )
  },
)
```

A list in `harness` replaces the agents the evaluation inherits from the `reeval.config.ts` file. Each agent reads its API key from the `.env.local` file. For more information about the `add`, `only`, and function forms, see [the `harness` option](/reference/options#harness). For more information about model ids per agent, see [Models](/agents/model).

</Step>
<Step title="Run the evaluation">

Run the evaluation on every agent it lists:

```bash
npx reeval run stream
```

To list the cells without starting an agent, pass `--dry-run`.

</Step>
<Step title="Read the pass rate per agent">

Read the block the run prints for the evaluation. Rows print under `harness`, one per cell, with passed attempts out of counted attempts. An agent that failed an attempt lists the assertions it failed under its row. Your counts can differ:

```text
fail             streams with Vercel AI SDK
  harness                      pass
  cursor:composer-2.5          4 of 4
  claude-code:claude-sonnet-5  4 of 4
  codex:gpt-5.6-luna           3 of 4
    adds the ai package        3 of 4
      expected file package.json to exist
    +1 more passed
```

Every agent cell is gated, so one agent that fails an attempt fails the evaluation. To pass a cell on a share of its attempts, set [the `gate` option](/reference/options#gate). For more information about the rows, see [Read a comparison](/results/output#read-a-comparison).

</Step>
<Step title="Read the effort per agent">

Read each agent's tool calls, time, and tokens from the `effort` view, because the block prints none of them for these cells. The view holds each cell's median tool calls, agent seconds, and tokens. Select the last run's rows:

```bash
npx reeval query "SELECT harness, tools_median, agent_s_median
  FROM effort WHERE run_id = :run" --run last
```

The rows print one agent per line. Your numbers differ:

```text
harness                      tools_median  agent_s_median
cursor:composer-2.5          12            0.4
claude-code:claude-sonnet-5  9             0.3
codex:gpt-5.6-luna           21            0.9
```

An agent that passes with fewer tool calls and seconds did the task with less work. To add tokens, select `tokens_median`. For more information about the `reeval query` command, see [Query past runs](/results/queries).

</Step>
</Steps>
