---
title: "Measure a skill"
description: "See whether a skill helped your harness."
---

You measure a skill by running one task on a control with no skill and a variant with the skill. The effect reads `helped`, `made it worse`, or `can't tell yet`.

## Run one task with and without the skill

<Steps>
<Step title="Write the evaluation">

In the `evals/environments.ts` file, define the control `page` and the variant `withSkill`. The control holds the page the task styles. The variant extends `page` and adds Anthropic's `brand-guidelines` skill, pinned to a commit.

```ts title="evals/environments.ts"
import { defineEnvironment } from '{{ pkg }}'

export const page = defineEnvironment('page', ({ directory }) => ({
  files: directory('./project'),
}))

export const withSkill = page.extendEnvironment(
  'brand-guidelines',
  ({ skill }) => ({
    skills: [
      skill.git('github:anthropics/skills', {
        ref: 'dbd4588f9e1033efb41dad4bef2f7947c8993d44',
        path: 'skills',
        only: ['brand-guidelines'],
      }),
    ],
  }),
)
```

For more information about placing skills, see [Give the agent skills](/environments/skills).

In the `evals/brand.eval.ts` file, run the evaluation in `page` and name the variant in `compare.variants`:

```ts title="evals/brand.eval.ts"
import { evaluate, expect } from '{{ pkg }}'
import { page, withSkill } from './environments.ts'

evaluate(
  "styles the page in Anthropic's brand",
  {
    environment: page,
    compare: { variants: [withSkill] },
    runs: 4,
    gate: { passRate: 0.75 },
  },
  async (c) => {
    await c.send(
      "Give index.html Anthropic's look: write styles.css with Anthropic's " +
        'brand colours and fonts, and link it from index.html.',
    )

    await expect
      .soft(c, 'links styles.css')
      .toHaveFile('index.html', /href="styles\.css"/)
    await expect.soft(c, 'brand orange').toHaveFile('styles.css', /#d97757/i)
    await expect(c, 'brand fonts').toHaveFile(
      'styles.css',
      /Poppins[\s\S]*Lora|Lora[\s\S]*Poppins/,
    )
  },
)
```

The prompt doesn't name the brand's colour or fonts, so `brand orange` and `brand fonts` pass only when the harness knows them. `runs: 4` gives each cell four attempts. Below four counted attempts a side, the effect stays `can't tell yet`. For more information about how reeval reaches the effect, see [Comparison](/core-concepts#comparison).

To also check that the variant loaded the skill, guard `toHaveCalledSkill` with `c.attempt.cell.role === 'variant'`, since the control has no skill to load ([Give the agent skills](/environments/skills#check-the-agent-used-the-skill)).

</Step>
<Step title="Require a minimum lift">

In the `evals/brand.eval.ts` file, set `minLift` on the comparison. `compare.minLift` is the smallest lift you accept, from -1 to 1.

```diff title="evals/brand.eval.ts"
-    compare: { variants: [withSkill] },
+    compare: { variants: [withSkill], minLift: 0.25 },
```

A variant whose lift may be below `0.25` fails. Its row then reads `helped, not by minLift 25`. For more information about this gate, see [Gate on lift](/evals/compare#gate-on-lift).

</Step>
<Step title="Run the comparison">

Run the evaluation with the harness named in the `reeval.config.ts` file:

```bash
npx reeval run brand
```

</Step>
<Step title="Read whether it helped">

Read the one block the run prints for the evaluation. Your counts can differ. When the variant helps, the block uses this shape ([Read a comparison](/results/output#read-a-comparison)):

```text
pass             styles the page in Anthropic's brand
  arm               pass
  page              0 of 4
  brand-guidelines  4 of 4  helped
  check             page    brand-guidelines
  brand orange      0 of 4  4 of 4
    expected styles.css to match /#d97757/i
  brand fonts       0 of 4  4 of 4
    expected styles.css to match /Poppins[\s\S]*Lora|Lora[\s\S]*Poppins/
  +1 more passed
```

`brand orange` and `brand fonts` are the rows that separate the cells. `links styles.css` passed on both, so it prints under `+1 more passed`. When the brand checks pass on both sides, the harness already knows the brand, and this task can't show the skill. For a runnable project, see [`with-library-skill-lift`](https://github.com/invertase/reeval/tree/main/examples/with-library-skill-lift).

For more information about the other gates, see [Compare setups](/evals/compare). For more information about asking which attempt did better, see [Ask which did better](/evals/compare#ask-which-did-better).

</Step>
</Steps>

## Compare skill versions

To measure a change to a skill, pin each commit on its own environment. This section uses Matt Pocock's `migrate-to-shoehorn` skill, which changed between two commits, on a `plain` environment that holds the `src/user.ts` file the task tests. The earlier commit is the control, and the later commit is the variant. In the `evals/environments.ts` file, add two environments:

```ts title="evals/environments.ts"
export const earlier = plain.extendEnvironment('earlier', ({ skill }) => ({
  skills: [
    skill.git('github:mattpocock/skills', {
      ref: '62f43a18177be6ec82da242e59ffbc490a4c22ea',
      path: 'skills/misc',
      only: ['migrate-to-shoehorn'],
    }),
  ],
}))

export const later = earlier.extendEnvironment('later', ({ skill }) => ({
  skills: [
    skill.git('github:mattpocock/skills', {
      ref: '697d4ce9742da558fd1ba6697c8e9775e2e302dd',
      path: 'skills/misc',
      only: ['migrate-to-shoehorn'],
    }),
  ],
}))
```

Both environments extend `plain`, so they share its files and differ only by the pinned commit. `later` replaces the skill of the same name, so the harness gets the later commit only. A commit in `ref` keeps the cells comparable. For more information about the helper, see [the `skill.git` helper](/reference/environment#skillgit).

In the evaluation file, set `compare.baseline` to `earlier` and `compare.variants` to `later`:

```ts title="evals/shoehorn.eval.ts"
{ runs: 4, compare: { baseline: earlier, variants: [later] } },
```

The check that separates the cells shows whether the later commit helped.
