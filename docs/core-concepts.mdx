---
title: "Core concepts"
description: "Understand the nouns reeval uses to evaluate a coding agent."
---

Each section defines one noun the reeval docs use. For more information about the code symbol behind each noun, see [Glossary](/reference/glossary).

## Run

A run is one `reeval run` command and every attempt it starts. Each evaluation gets one cell per harness, environment, and sandbox. Each case repeats those cells, and the [`runs` option](/reference/options#runs) sets the attempts per cell.

## Evaluation

An evaluation is one `evaluate()` call in a `*.eval.ts` file beside the skill, docs, or tool it tests. The [evaluation](/evals/evaluate) gives the harness a task and checks what the agent did.

## Harness

A harness is the coding agent that does the task. The `harness` option identifies the [harness](/harnesses) that reeval starts in the sandbox, sends it each prompt, and records its messages and tool calls.

## Environment

An environment is what the harness gets in an attempt, such as skills, Model Context Protocol (MCP) servers, rules, files, setup commands, variables, and secrets. The `defineEnvironment()` function represents an [environment](/environments), including a comparison's control and variants.

## Sandbox

A sandbox is the container an attempt runs in. The `sandbox` option identifies the [sandbox](/sandboxes) that holds the workspace, the harness, and whatever the environment adds.

## Egress

Egress is the hosts a sandbox can reach. A restricted policy leaves only the [gateway](/environments/egress).

## Cell

A cell is one harness, environment, and sandbox of an evaluation, keyed like `claude-code:claude-sonnet-5/-/docker`, where `-` means no environment. Each cell's [gate](/reference/options#gate) turns its attempts into its outcome, so a comparison's control and each variant pass or fail separately.

## Attempt

An attempt is one try at a cell in a fresh sandbox, and it ends with an outcome of pass, fail, infra error, cancelled, or skipped. Agents are non-deterministic, so one attempt proves little, and the [`runs` option](/reference/options#runs) sets how many attempts each cell gets.

## Turn

A turn is one `c.send(prompt)` and everything the harness does in reply. The turn holds the final message, the transcript, the token usage where the harness reports it, the model that served it, and the workspace diff; one attempt can have several [turns](/evals/turns).

## Transcript

A transcript is every message and tool call of an attempt, in order, saved in the `transcript.jsonl` file with the run. When a check fails, the [transcript](/results/debugging#read-a-transcript) shows what the agent did.

## Check

A check is an `expect` assertion on what an attempt produced, such as a file, a command's result, a tool call, or a [judge](/evals/judges)'s verdict. An attempt passes when all of its [checks](/evals/checks) pass.

## Comparison

A [comparison](/evals/compare) runs one evaluation, through the `compare` option, on a control without your change and on one or more variants with it, then compares their pass rates. Each variant reads `helped` or `made it worse` when the difference is [clear of chance](/evals/statistics), and `can't tell yet` below four counted attempts a side or when the result is too close to call.

## Record

A record is the saved result of a run, with every attempt's outcome, checks, token usage, transcript, and diff. A scratch record lives in the `.reeval/runs/` directory, whereas [recording](/runs/recording) saves selected records beside the code they ran on.

## Analysis

Analysis is what a language model writes about a run, such as the insights that explain each evaluation's result beside the Remarks that flag problems with the evaluations themselves. Analysis needs an [analysis model](/results/analysis#set-an-analysis-model) and never changes an outcome or the exit code.

## Profile

A profile is a named preset in the config's `profiles` that sizes a run. The `pr` and `nightly` [profiles](/runs/profiles) written by the `reeval init` command are examples, and each run records its selected profile.
