## Configuration

```ts title="with-library-skill-lift.eval.ts"
environment: page,
compare: { variants: [withSkill] },
harness: [
  claudeCode({ model: 'claude-sonnet-5' }),
  codex({ model: 'gpt-5.6-luna' }),
],
runs: 4,
```

A [run](/reference/glossary#run) multiplies [agents](/reference/glossary#agent), [environments](/reference/glossary#environment), and [attempts](/reference/glossary#attempt) into [sandboxes](/reference/glossary#sandbox), one sandbox per attempt. The [`harness`](/reference/glossary#harness) option names the agents, and in a comparison the environments are the [baseline](/reference/glossary#baseline) and its variants. The [`runs`](/reference/options#runs) option sets the attempts.

## Evaluation

```ts title="with-library-skill-lift.eval.ts"
await c.send(
  "Give index.html Anthropic's look: write styles.css with Anthropic's " +
    'brand colors and fonts, and link it from index.html.',
)

await expect.soft(c, 'brand orange').toHaveFile('styles.css', /#d97757/i)
```

Each attempt of an [evaluation](/reference/glossary#evaluation) puts the agent, the environment, and the [task](/reference/glossary#task) in one sandbox. The [workspace](/reference/glossary#workspace) holds the [artifacts](/reference/glossary#artifacts) and the [transcript](/reference/glossary#transcript), and grading reads that workspace. [Assertions](/reference/glossary#assertion) and [judgments](/reference/glossary#judgment) grade one attempt, and [questions](/reference/glossary#question) read across attempts.

## Results

```text
  effort           tools  time
  math             1      1.0s
  project-layout   1      <0.1s
```

The run reports six [measures](/reference/glossary#measures): pass rate, tokens, tool calls, [turns](/reference/glossary#turn), cost, and time. A [comparison](/reference/glossary#comparison) reads [lift](/reference/glossary#lift) as the variant against the baseline, and [past runs](/reference/glossary#past-runs) as this run against earlier ones. [Analysis](/reference/glossary#analysis) reports the [answers](/reference/glossary#answers), then the [insights](/reference/glossary#insights).
