The full detail on every reeval feature, one topic per page. Parts of it (the CLI help, the `reeval query` views, the option keys, exit codes and the record's fields) are generated from the code, so they match the version you run.

```ts
import { defineConfig, evaluate, expect, group } from '{{ pkg }}'
import { cursor } from '{{ pkg }}/harness'
import { docker } from '{{ pkg }}/sandbox'
```

## Exports

| Import | What it exports |
|---|---|
| `{{ pkg }}` | `defineConfig`, `defineEnvironment`, `group`, `evaluate`, `expect`, `DEFAULT_EGRESS_ALLOW`, `DEFAULT_SKILL_EXCLUDE`, `HarnessCapabilityError`, and the types |
| `{{ pkg }}/harness` | `cursor`, `claudeCode`, `antigravity`, `opencode`, `goose`, `pi`, `codex`, `fakeHarness` |
| `{{ pkg }}/sandbox` | `docker`, `fakeSandbox` |
| `{{ pkg }}/judge` | `fakeJudge`, `fakeAnalysis`, `DEFAULT_THRESHOLD`, `RECOMMENDED_JUDGE_MODEL` |
| `{{ pkg }}/view` | Browser-safe run headers, the studio's file layout and view-models |
