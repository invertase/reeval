---
title: "Run record reference"
description: "A run record holds one run's cells, attempts, assertions, judgments, and the environment each ran in."
---

The `reeval show --json` command prints one run's record. The record is the `<runId>.json` file in the `.reeval/runs/` directory, or the same name in the history folder, with artifacts in the `<runId>` directory.

For more information about saving a record, see [Recording](/evaluations/runs/recording). For more information about the saved result, see [Record](/reference/glossary#record). For more information about querying recorded runs, see [Query views](/reference/query-views).

## Value types

Each row is one closed alias. `RecordMode` is the `record` option.

[//]: # (generated:record-values)

| Type | Values |
|---|---|
| `Outcome` | `'pass'`, `'fail'`, `'infra_error'`, `'skipped'` |
| `ErrorKind` | `'assertion'`, `'timeout'`, `'aborted'`, `'infra'`, `'judge'` |
| `TurnStatus` | `'completed'`, `'aborted'`, `'error'` |
| `ArtifactLevel` | `'all'`, `'failures'`, `'none'` |
| `RecordMode` | `'manual'`, `'ci'`, `'always'` |
| `FamilyVerdict` | `'lift'`, `'drop'`, `'noise'`, `'insufficient'` |

[//]: # (/generated:record-values)

`CellRole` is `control` or `variant`. `CellGate` is `all`, `{ passRate: number }`, or `none`. `CheckVerdict` is `discriminates`, `both-pass`, `both-fail`, or `mixed`. `EgressPolicy` is `proxy`, `allow-all`, `deny-all`, or `{ allow: string[] }`. `SkillPlacement` is `harness` or `workspace`. `WebEventType` is `web-search` or `web-fetch`. `CompareCut` is `within` or `across`.

For more information about which hosts a sandbox can reach, see [Egress](/configuration/environments/egress).

## Record types

`kind` is `reeval-run`, and `schemaVersion` is `1`. `git` is null outside a Git repository, or when that repository has no commits. `author` is `ci` on a CI run, and otherwise a slug of the Git user name. `config.concurrency` is how many attempts run together, and `config.configHash` omits it.

For more information about the keys on `stack.judge.state`, see [`c.judge()`](/reference/attempt-context#cjudge).

## `RunnerInfo`

On a CI run, `RunRecord.runner` has `kind` `ci` and `provider` `github`, `gitlab`, or `unknown`. `runUrl`, `attempt`, and `pr` (`{ number, baseRef }`) are what that provider reports, or null. A local run has `kind` `local` and `hostHash`, a hash of the host name.

## `TokenUsage`

`TokenUsage` is the counts on `Cost.usage`, an attempt's `usage`, and a turn's `usage`. `input` excludes `cacheRead` and `cacheWrite`. The prompt total adds both. `reasoning` is part of `output`, or null when none are reported.

## `AttemptError`

`AttemptRecord.error` is why an attempt failed, or null. `kind` is an `ErrorKind`. `message` is the text. `prepare` is set when sandbox preparation fails. `resource` is set when the sandbox runs out of a resource.

## `PrepareFailureRecord`

`AttemptError.prepare` records a sandbox preparation that failed. `class` is `config`, `transient` after the retries, or `resource`. `stage` is `image`, `from`, `dockerfile`, `harness`, `install`, `plugin`, or `workspace`. `ref` is what was prepared, `repo#ref:path` for a Git workspace. `cause` is `enospc`, `oom`, or null. `log` is the build log or null, and `setBy` names the levels that set the sandbox.

## `ResourceFailureRecord`

`AttemptError.resource` means the sandbox ran out of memory, and the outcome is `infra_error`. `cause` is `oom`. `kills` is how many processes the kernel killed.

## `AssertionRecord`

An `AssertionRecord` is one settled `expect` or `expect.require` call on `AttemptRecord.assertions`. `checks` on that attempt lists each `c.exec` command.

`label` is the supplied `expect` label. Without one, it is the matcher plus its first argument or named subject, cut at 60 characters. Repeats get ` #2`, ` #3`, and later suffixes. `labelled` is true when the evaluation supplies a label. `matcher` is the matcher path. `status` is `pass`, `fail`, or `error`. `soft` is false for `expect.require`. `at` is the call's `path:line`. `message` is cut at 1 KB. `durationMs` is set on async matchers only.

## `StartRetry`

A `StartRetry` is one entry of `AttemptRecord.startRetries`. `error` is `<harness kind>: session did not become ready within <startTimeout>`. `waitedMs` is how long that start waited.

## `CellCheck`

`CellRecord.checks` tallies one label over the cell's counted attempts. `pass`, `fail`, `error`, and `notRun` are those counts, and `control` repeats them for the baseline. `verdict` is `discriminates` when every answered instance passes on one side and fails on the other, `both-pass` when every answered instance passes on both sides, `both-fail` when every answered instance fails on both sides, or `mixed` otherwise. It is absent when either side has no pass or fail.

## `EvalCompareMeta`

`EvalEntry.compare` names the baseline when the evaluation uses `compare`. `baseline` is that environment's name. When `compare.baseline` was omitted, `from` is `environment` for the cascaded environment, or `empty` for an empty environment named `baseline`.

## `CompareAnswer`

`EvalEntry.answers` holds one `CompareAnswer` per pairwise question. `outcome` and `passRate` do not depend on it. `question`, `model`, and `resolvedModel` identify the question and the model. `votes` holds `PairVote` values, and `rates` holds `wins` out of `n` per `cut` and `name`. `error` is set when the model call fails. `artifacts` is `true` or capture names. `input` is a `FileRef` for the `questions/<n>.json` file. `stateOptions` is the inputs each side showed.

For more information about each input, see [the `questions` option](/reference/options#questions).

## `PairVote`

A `PairVote` judges one pair in one order. `cut` is `within` (two environments, one harness) or `across` (two harnesses, one environment). `harness` is set on `within`, and `arm` names the environment on `across`. `run` starts at 1. `a` and `b` name the sides, and `winner` is `a`, `b`, or `tie`. `swapped` is true when `b` was shown first. `reason` and `artifacts` are omitted when absent.

## `AttemptRecord.turns`

A turn's `usage` and `model` are null when the harness reports neither. `error` is the first error, cut at 1 KB, or null. `unreported` lists `web-search` or `web-fetch` when that event cannot be reported.

## `AttemptRecord.activity`

`webSearches` and `webFetches` are null when a turn cannot report them. `stalledTools` counts stalled tool events, and `maxToolMs` is the longest tool duration, or null.
