`reeval mcp` is an MCP server built into the CLI. Cursor, Claude Code or any MCP client launches it and asks the history what `reeval query`, `reeval show`, `reeval compare` and `reeval history` answer.

```bash
npx reeval mcp
npx reeval mcp --http --port 4986
```

```text

Ctrl-C to stop.
```

- **Protocol:** MCP 2026-07-28, stateless (`server/discover`, no sessions). Clients that still open with the 2025 `initialize` handshake are served too.
- **stdio** (the default): the client starts `reeval mcp` and it ends when the client closes its stdin. Its stdout is the protocol, so anything the config prints goes to stderr.
- **`--http`:** Streamable HTTP, POST `/mcp`, a fresh server per request, on `127.0.0.1` until Ctrl-C. No token by default. A taken port fails; there's no next port.
- **Project:** the one `--config` names, or the nearest config to the current directory.

## Tools

| Tool | Arguments | Returns |
|---|---|---|
| `history` | `filter`, `limit`, `all` | `reeval history --json` |
| `show` | `run`, `format` (`json` or `md`) | `reeval show --json`, or `summary.md` as `markdown` |
| `compare` | `base`, `head` | `reeval compare --json` |
| `analysis` | `run` | Saved and cached analyses of the run, newest first; never calls a model |
| `transcript` | `run`, `attempt`, `offset`, `limit` | An attempt's transcript lines (200 by default), `total` and its resource `uri` |
| `query_<view>` | `where`, `limit` | `{ columns, rows, truncated }` from the view |
| `query` | `sql`, `limit` | The same, for one `SELECT` or `WITH` statement |
| `query_schema` | none | `reeval query --schema --json`, as `objects` |

There's one `query_<view>` tool per [view](/reference/cli/query#views): `query_lift`, `query_family_lift`, `query_effort`, `query_contrasts`, `query_factor_effects`, `query_skill_reads`, `query_context_use`, `query_skill_files`, `query_flaky_cells`, `query_drift`, `query_failing_attempts`, `query_eval_trend`, `query_verdict_flips` and `query_check_discrimination`. Its `where` takes the view's columns, each equal to a value (`null` matches `NULL`). Rows default to 100 and stop at 1000; `truncated` says there were more.

A `run` is a [run reference](/reference/cli#run-references), `latest` by default. An `attempt` is its key from `show` (`evals/a.eval.ts › writes ok # fake/-/fake#1`), or its id (`fake/-/fake#1`) when only one eval has it.

```json
{
  "columns": ["eval_key", "run_id", "started_at", "branch", "pr_number", "recorded", "outcome", …],
  "rows": [
    {
      "eval_key": "evals/a.eval.ts › writes ok",
      "run_id": "20260928T064231Z_e404369_cursor-agent_xxa1",
      "outcome": "pass",
      "pass_at_1": 1,
      …
    }
  ],
  "truncated": false
}
```

Each result is that JSON as text and as `structuredContent`. Every tool is marked read-only and idempotent.

## Resources

| URI | Contents |
|---|---|
| `reeval://runs/<runId>` | The run record; the list has every recorded and scratch run, newest first |
| `reeval://runs/<runId>/transcripts/<attempt>` | The attempt's `transcript.jsonl`, with the attempt key percent-encoded |

## Security

- **Read-only.** SQL runs on the same read-only connection as `reeval query`, one `SELECT` or `WITH` statement at a time, so `ATTACH`, `PRAGMA` and `VACUUM INTO` are refused. The only write is `.reeval/history.db` catching up with new records.
- **No evals run.** A run spends keys, starts containers and takes minutes: run it with `reeval run` in a terminal.
- **Masked.** Records are masked when reeval writes them, and everything `reeval mcp` returns is masked again against its own environment. It loads no `.env` files.
- **Scoped.** Runs are references, never paths. A transcript is read only from inside its run's folder, after resolving symlinks.
- **HTTP:** it binds `127.0.0.1` and checks `Host` and `Origin`, so a web page can't reach it through DNS rebinding. Other hosts and origins get 403; GET gets 405.

## A token

```bash
REEVAL_MCP_TOKEN=$(openssl rand -hex 32) npx reeval mcp --http
npx reeval mcp --http --token "$REEVAL_MCP_TOKEN"
```

With `--token <value>` or `REEVAL_MCP_TOKEN` set (the flag wins), every request needs `Authorization: Bearer <value>`; without it, or with another value, it gets 401. reeval never prints the token, and masks it like any secret.

Set one when something other than you can reach the port:

- **Beyond localhost:** a `--host` other than `127.0.0.1`, `localhost` or `::1` (reeval warns), or a forwarded port.
- **Shared machines:** other users on the same host can reach `127.0.0.1` too.
