---
title: The run record
description: Every field of a run's JSON record, and the history folder layout.
---

Each run is one JSON file, `<runId>.json`, plus optional artifacts in `<runId>/`. The record is immutable once written. `reeval show <run> --json` prints it.

A record written before a field existed still loads everywhere: reeval reads the missing field as empty (`[]`, or `false` for `todo`). A record from a newer reeval loads too, ignoring fields this reeval doesn't know, unless its `schemaVersion` is higher: then reeval skips it with a warning to upgrade.

```bash
npx reeval show latest --json | jq '.evals[] | select(.outcome != "pass") | .id'
```

## Layout

```text
evals/.history/                            commit this
  .gitignore                               un-ignores recorded files (`*.log` and the rest)
  <runId>.json                             the record
  <runId>/summary.md                       the run as Markdown
  <runId>/worktree.patch                   uncommitted changes, when the run was dirty
  <runId>/<eval-slug>/<cell-slug>/<n>/     one directory per attempt
    transcript.jsonl                       timed agent events (see Transcripts)
    diff.patch                             the agent's changes, dependency noise dropped
    judge-input.json                       what each judge call saw
    setup.log                              each environment setup step's output
    checks/<n>.log                         each c.exec: command, exit code, stdout, stderr
    artifacts/<name>.png                   each c.capture() PNG (`history.artifacts` keeps it)
.reeval/                                       scratch: gitignore it
  current                                  the run id minted (or resumed) this session
  staging/<runId>/                         a run in progress, until assemble
  runs/<runId>.json + <runId>/             every reeval run, same shape
  debug/<runId>/…                          local debug data, never recorded
  history.db                               reeval query's projection
```

The record is `kind: "es-run"`, `schemaVersion: 1`. While reeval is pre-release the schema changes in place, and an older record may not parse. Single tool outputs, check streams and per-file diffs over 128 KB keep their head and tail, a truncation marker and the full text's sha256. Records are redacted before they're written.

## Reading one

Start at `evals[]` where `outcome != "pass"`, then its `cells[]` for pass rates, roles and lift, then each failing attempt's `error` and `judgements`. Open the files its `files` points to.

```json title="evals/.history/<runId>.json (trimmed)"
{
  "kind": "es-run",
  "schemaVersion": 1,
  "runId": "20260926T170558Z_bd6205e_ada-lovelace_sycz",
  "status": "complete",
  "summary": { "evals": 1, "attempts": 4, "pass": 2, "fail": 2, "notGated": 2, "infraError": 0, "skipped": 0 },
  "evals": [{ "id": "evals/skill.eval.ts › house greeting › greets in the house style", "outcome": "pass", "…": "…" }]
}
```

## Fields

The type definitions are in `packages/reeval/src/history/types.ts`; the environment, egress and image records are in `src/types.ts`. This section is generated from them.

### Value types

[//]: # (generated:record-values)

| Type | Values |
|---|---|
| `Outcome` | `'pass'`, `'fail'`, `'infra_error'`, `'skipped'` |
| `ErrorKind` | `'assertion'`, `'timeout'`, `'aborted'`, `'infra'`, `'judge'` |

[//]: # (/generated:record-values)

`runner` is `{ kind: 'ci', provider, runUrl, attempt, pr: { number, baseRef } | null }` in CI, or `{ kind: 'local', hostHash }` on your machine.

An attempt's `error` is `{ kind, message, prepare? }`. `prepare` is set when its sandbox couldn't be prepared before the run: `{ class, stage, ref, cause, log, setBy }`, with `class` one of `config`, `transient` or `resource`, and the same on every attempt that needed that sandbox (see [Sandbox providers](/reference/sandbox/providers)). A git `workspace` that couldn't be fetched sets it too, with `stage: "workspace"` and the workspace as `ref`, such as `../repo#v9`. Such an attempt never started, so it has no artifacts directory.
