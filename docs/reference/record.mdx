---
title: The run record
description: Every field of a run's JSON record, and the history folder layout.
---

Each run is one JSON file, `<runId>.json`, plus optional artifacts in `<runId>/`. The record is immutable once written. `reeval show <run> --json` prints it.

A record written before a field existed still loads everywhere: reeval reads the missing field as empty (`[]`, or `false` for `todo`). A record from a newer reeval loads too, ignoring fields this reeval doesn't know, unless its `schemaVersion` is higher: then reeval skips it with a warning to upgrade.

```bash
npx reeval show latest --json | jq '.evals[] | select(.outcome != "pass") | .id'
```

## Layout

```text
evals/.history/                            commit this
  .gitignore                               un-ignores recorded files (`*.log` and the rest)
  <runId>.json                             the record
  <runId>/summary.md                       the run as Markdown
  <runId>/insights.json                    reeval analyze --insights' sentences, create-only
  <runId>/worktree.patch                   uncommitted changes, when the run was dirty
  <runId>/<eval-slug>/questions/<n>.json   what compare question n's model was sent
  <runId>/<eval-slug>/<cell-slug>/<n>/     one directory per attempt
    transcript.jsonl                       timed agent events (see Transcripts)
    diff.patch                             the agent's changes, dependency noise dropped
    judge-input.json                       what each judge call saw
    setup.log                              each environment setup step's output
    checks/<n>.log                         each c.exec: command, exit code, stdout, stderr
    artifacts/<name>.png                   each c.capture() PNG (`history.artifacts` keeps it)
.reeval/                                       scratch: gitignore it
  current                                  the run id minted (or resumed) this session
  staging/<runId>/                         a run in progress, until assemble
  runs/<runId>.json + <runId>/             every reeval run, same shape
  debug/<runId>/…                          local debug data, never recorded
  history.db                               reeval query's projection
```

The record is `kind: "reeval-run"`, `schemaVersion: 1`. The schema only grows: a newer reeval reads an older record, and an older reeval skips a record with a higher `schemaVersion`, saying to upgrade.

Single tool outputs, check streams and per-file diffs over 128 KB keep their head and tail, a truncation marker and the full text's sha256. Records are redacted before they're written.

## Reading one

Start at `evals[]` where `outcome != "pass"`, then its `cells[]` for pass@1 (`passRate`), roles and lift, then each failing attempt's `error` and `judgements`. Open the files its `files` points to.

```json title="evals/.history/<runId>.json (trimmed)"
{
  "kind": "reeval-run",
  "schemaVersion": 1,
  "runId": "20260926T170558Z_bd6205e_ada-lovelace_sycz",
  "status": "complete",
  "summary": {
    "evals": 1, "attempts": 4, "pass": 2, "fail": 2,
    "notGated": 2, "infraError": 0, "skipped": 0
  },
  "evals": [{
    "id": "evals/skill.eval.ts › house greeting › greets in the house style",
    "outcome": "pass",
    "…": "…"
  }]
}
```

## Fields

The type definitions are in `packages/reeval/src/history/types.ts`; the environment, egress and image records are in `src/types.ts`. This section is generated from them.

[//]: # (/generated:record-values)

`runner` is `{ kind: 'ci', provider, runUrl, attempt, pr: { number, baseRef } | null }` in CI, or `{ kind: 'local', hostHash }` on your machine.

An attempt's `error` is `{ kind, message, prepare?, resource? }`:

| Field | Set when | Shape |
|---|---|---|
| `prepare` | Its sandbox couldn't be prepared before the run (see [Sandbox providers](/reference/sandbox/providers)), the same on every attempt that needed it | `{ class, stage, ref, cause, log, setBy }`, `class` one of `config`, `transient` or `resource` |
| `prepare` | A git `workspace` couldn't be fetched | `stage: "workspace"`, the workspace as `ref`, such as `../repo#v9` |
| `resource` | The kernel killed `kills` processes at the sandbox's memory limit | `{ cause: 'oom', kills }` |

An attempt with `prepare` never started, so it has no artifacts directory. One with `resource` has `kind: infra` and outcome `infra_error`, whatever its checks said, so it's left out of pass rates and lift.

## Insights

`reeval analyze <run> --insights` writes `<runId>/insights.json` beside the record, once: delete it to write new ones. `reeval show` prints it with the run. It's `kind: "reeval-insights"`, `schemaVersion: 1`, and grows like the record.

```json title="evals/.history/<runId>/insights.json (trimmed)"
{
  "kind": "reeval-insights",
  "schemaVersion": 1,
  "runId": "20261020T231903Z_2e69951_cursor-agent_8s1m",
  "model": "fake",
  "promptVersion": "insights-v3",
  "factsHash": "sha256:0d56643daa2ea23e32a66492facca73fc5b3a85c6051d4f8690abec7c5281a18",
  "usage": { "inputTokens": 0, "outputTokens": 0, "costUsd": null },
  "headline": {
    "text": "9 fail; start with \"recommends Genkit for $task\".",
    "cites": ["evals%2Fchoose.eval.ts › recommends Genkit for $task"]
  },
  "evals": [{
    "evalId": "evals%2Fchoose.eval.ts › recommends Genkit for $task",
    "intent": {
      "job": "choose", "across": "none",
      "question": "Does the agent pick Genkit?",
      "subject": { "tool": "Genkit" },
      "name": "states-intent", "key": "2c0c59de…"
    },
    "answer": {
      "text": "Not for a Python agent: 0 of 2 tries passed.",
      "cites": ["evals%2Fchoose.eval.ts › recommends Genkit for $task/a Python agent"]
    },
    "findings": [],
    "rows": [{ "row": "…/a Python agent", "text": "It also names LangChain, …", "cites": ["…"] }],
    "namedTools": [{ "attempt": "…/a chat app/advisor+-+fake#1", "tools": ["Genkit", "LangChain"] }]
  }],
  "remarks": [],
  "validation": { "dropped": 0, "regenerated": 0, "drops": [] }
}
```

| Field | What it holds |
|---|---|
| `model`, `promptVersion` | The analysis model and the prompts' version that wrote it |
| `factsHash` | `sha256:` of the run's facts as canonical JSON; when the facts no longer match, `reeval show` leaves the insights out with a note |
| `usage` | Tokens over every call; `costUsd` is `null`, since reeval has no prices |
| `headline` | One sentence on the run, printed before the tally, or `null` |
| `evals[].evalId` | The eval's or family's path: its file and name, `›` between them |
| `evals[].intent` | The classification: `job` (`choose`, `finish` or `other`), `across`, `question`, `subject` (`tool`, `change`), `name` (`states-intent`, `no-intent` or `contradicts`) and `key`, the hash of what it read |
| `evals[].answer` | Its answer, at most two sentences, or `null` |
| `evals[].findings` | Sentences under a choose or finish eval that measures a change |
| `evals[].rows` | A sentence under each row it names (`row`, a fact path) |
| `evals[].namedTools` | On a choose eval, the tools each attempt's final message names (`<cell path>#<n>`) |
| `remarks` | Reserved for later remarks on the run; empty |
| `validation` | `dropped`, the sentences the checks dropped, and `regenerated`, those asked for again |
| `validation.drops` | Each dropped sentence: `slot` (`<eval> › answer`, `› finding <n>`, `› row <path>`, `› named tools <attempt>` or `headline`), `text` and `reason`; absent in files written before it |
| `error` | Set when writing the insights failed; `reeval show` prints it instead |

Each sentence is `{ text, cites }`. A cite is a fact path (`<eval>`, `<eval>/<cell>`, `<eval>/<cell>/checks/<label>`, `<eval>/<cell>/effort`, `<family>/<case>`) or a transcript line, `transcript:<cell path>#<n>#L<line>`. Paths percent-encode `%`, `/` and `+` inside each part.

## What a record can't pin down

| Not pinned | Why |
|---|---|
| The agent's output | It's sampled |
| The model behind a name | Providers update models in place |
| Web search, package registries | Network-dependent |
| Locally built images | They have an image id but no registry digest |

A rerun can differ on any of these even when every fingerprint matches.
