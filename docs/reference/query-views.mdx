`reeval query` reads views and tables in the `.reeval/history.db` file.

For more information about writing a query, see [Query past runs](/results/inspection/queries).

## `reeval query`

`reeval query` takes one SQL statement, or the name of one view or table. `reeval query` with no argument lists the views and the tables. A name that matches neither is an error, and so is a second statement. Text rows print a null as `·` and clip any other cell except a `sql` column to 60 characters.

## `--run`

The `--run` flag binds a run id to `:run`, `$run`, and `@run`, and does not rewrite the statement. `last` and `latest` select the maximum `started_at`, then the greatest `run_id`. Any other value is an exact run id, or a prefix of exactly one run id. A bare view or table name adds `WHERE run_id = :run`. The flag is refused for `flaky_cells` and `check_streaks`, which have no `run_id` column, and when the statement names one of those parameters without the flag, or the flag is set and the statement names none of them.

## `--json`

The `--json` flag prints rows as a JSON array and does not clip them. With `--schema`, or with no statement, it prints the schema as JSON.

## `--schema`

The `--schema` flag lists every exposed view and table with its columns and runs no statement. With no statement, text output also includes example statements.

## `--rebuild`

The `--rebuild` flag rebuilds the `.reeval/history.db` file from the run records before the query. Without the flag, `reeval query` updates that file when a record is added, changed, or removed.

## `history.db`

The `.reeval/history.db` file is a SQLite database in the `.reeval` directory. A recorded run in the history folder replaces the scratch copy of that run id in the `.reeval/runs` directory. The query connection is read-only, and a write is refused.

## `lift`

`lift` lists one row per variant cell in a run, beside its baseline.

```bash title="Query"
reeval query "SELECT eval_key, points, lo, hi FROM lift WHERE within_noise = 0"
```

`within_noise` is 1 when the interval contains zero.

## `family_lift`

`family_lift` lists one row per variant of a pooled `evaluate.each` in one run.

```bash title="Query"
reeval query "SELECT name, variant, points FROM family_lift"
```

## `effort`

`effort` lists one row per cell, with a variant's ratios against its baseline.

```bash title="Query"
reeval query "SELECT eval_key, variant, tools_ratio FROM effort"
```

## `contrasts`

`contrasts` lists one row per pair of arms on one harness and sandbox when an evaluation has two or more variants.

```bash title="Query"
reeval query "SELECT eval_key, a_key, b_key, points FROM contrasts"
```

## `question_pairs`

`question_pairs` lists one row per pair of sides on a pairwise question.

```bash title="Query"
reeval query "SELECT question, a, b, a_wins, b_wins FROM question_pairs"
```

## `attempt_answers`

`attempt_answers` lists one row per answer to a question asked of each attempt on its own, with the attempt's outcome and cell.

```bash title="Query"
reeval query "SELECT question, choice, outcome FROM attempt_answers"
```

## `factor_effects`

`factor_effects` lists one row per factor level against a baseline.

```bash title="Query"
reeval query "SELECT factor, level, tier, points FROM factor_effects"
```

`tier` is `controlled`, `pooled`, `paired`, `observed`, or `not_measured`. `run_id` is null for `pooled` and `not_measured`.

## `skill_reads`

`skill_reads` lists one row per attempt and placed skill.

```bash title="Query"
reeval query "SELECT skill, reads, read_line FROM skill_reads"
```

A read is a tool target containing `skills/<name>/`, or a `skill`, `Skill`, or `load_skill` call whose target is the skill name.

## `context_use`

`context_use` lists one row per attempt and tool-call class.

```bash title="Query"
reeval query "SELECT class, calls, example FROM context_use"
```

`class`, a heuristic, is `context`, `dependency`, `web`, `verify`, or `workspace`.

## `skill_files`

`skill_files` lists one row per file the environment declared, on one attempt.

```bash title="Query"
reeval query "SELECT path, reads, first_line FROM skill_files"
```

## `flaky_cells`

`flaky_cells` lists one pooled row per cell that both passed and failed, with no `run_id` column.

```bash title="Query"
reeval query "SELECT eval_key, cell_key, verdict, cause FROM flaky_cells"
```

`verdict` is `flaky` when `counted` is at least `min_attempts`, and `insufficient` otherwise. `cause` is `agent`, `check`, `judge`, or `infra`.

## `drift`

`drift` lists one row where a cell's fingerprint differs from the previous run.

```bash title="Query"
reeval query "SELECT eval_key, changed, noise FROM drift"
```

`noise` is 1 when only runtime state changed.

## `failing_attempts`

`failing_attempts` lists each attempt whose `outcome` is `fail` or `infra_error`, one row per placed skill.

```bash title="Query"
reeval query "SELECT eval_key, harness, outcome FROM failing_attempts"
```

With no placed skill, `skill` is null.

## `eval_trend`

`eval_trend` lists one row per evaluation per run.

```bash title="Query"
reeval query "SELECT eval_key, outcome, pass_at_1 FROM eval_trend"
```

## `verdict_flips`

`verdict_flips` lists one row where a judgment's `pass_rate` on a cell differs from `prev_pass_rate`.

```bash title="Query"
reeval query "SELECT question, prev_pass_rate, pass_rate FROM verdict_flips"
```

## `check_discrimination`

`check_discrimination` lists one row per assertion on a variant cell, beside its baseline.

```bash title="Query"
reeval query "SELECT label, verdict FROM check_discrimination"
```

`verdict` is `discriminates`, `both-pass`, `both-fail`, or `mixed`.

## `check_rates`

`check_rates` lists one row per assertion on a cell in a run.

```bash title="Query"
reeval query "SELECT label, pass, fail, rate FROM check_rates"
```

`rate` divides `pass` by the sum of `pass` and `fail`, and is null when that sum is zero. The `error` and `not_run` counts stay out of the sum.

## `check_streaks`

`check_streaks` lists how many recorded runs in a row an assertion passed, for one cell, fingerprint, and branch, with no `run_id` column.

```bash title="Query"
reeval query "SELECT label, streak_runs, ended_by FROM check_streaks"
```

On a variant, the streak counts a run only when the variant and the baseline both pass.

## Tables

These tables store the projected rows. `reeval query --schema` lists these columns. That listing omits `meta`, `files`, `family_lift_m`, and the derived `*_m` fact tables; it keeps `question_pairs_m` and `attempt_answers_m`.

In `tool_calls`, `ok` is 1 or 0, or null for a call whose result the harness never reported. Count failures with `ok = 0`.
