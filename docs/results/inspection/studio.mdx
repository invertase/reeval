title: "Browse studio runs"
description: "Browse run history in the studio page, paired with your local runs."
---

The studio is a web page over the same run history the `reeval history` command lists, which it reads from your machine. It shows every recorded run, each run's evaluations, cells, and attempts, and each attempt's transcript. For more information about recording runs, see [Recording](/evaluations/runs/recording).

## Open the studio

The `reeval studio` command serves the history directory from the `reeval.config.ts` file, plus the unrecorded runs in the `.reeval/runs` directory, on `127.0.0.1`, and opens the studio page in the browser:

```bash
npx reeval studio
```

The command prints the address and keeps running until you press `Ctrl-C`:

```text
reeval studio · my-app · serving http://127.0.0.1:4984 (loopback only)
  https://…/studio?s=http%3A%2F%2F127.0.0.1%3A4984&run=…#t=…
Ctrl-C to stop.
```

The address carries a one-time token, which the page trades for a session, and the command refuses a request without it or from another page, so open the printed address rather than typing the port.

For more information about every flag of `reeval studio`, see [CLI](/reference/cli#reeval-studio).
