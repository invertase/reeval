Set the `harness` option to a harness factory with a `model` to choose an agent. For the definition, see [Agent](/reference/glossary#agent) in the Glossary.

For more information about installing reeval, see [Quick start](/quickstart).

## Choose an agent

In the `reeval.config.ts` file, pass one factory from the `{{ pkg }}/harness` module. With no `harness` option, the default harness is Cursor. Each harness is its own cell.

```ts title="reeval.config.ts"
import { defineConfig } from '{{ pkg }}'
import { claudeCode } from '{{ pkg }}/harness'

export default defineConfig({
  harness: claudeCode({ model: '<model>' }),
})
```

For more information about setting `model` and `effort`, see [Set the agent's model](/agents/model). For more information about running one evaluation on several harnesses, see [Compare harnesses](/recipes/agent-comparison).

## Set the harness options

Every factory takes these options beside `model`, so the harness pages don't repeat them. Set them in the factory call:

```ts title="reeval.config.ts"
harness: claudeCode({
  model: '<model>',
  id: 'claude-code:baseline',
  maxConcurrent: 2,
  startTimeout: '3m',
}),
```

<Property name="id" type="string" optional>
  Cell id. Defaults to the harness name followed by the model, such as `claude-code:<model>`, with `[effort=<value>]` added when `effort` is set. The id uses letters, digits, and `._:@+-=[]`.
</Property>

<Property name="maxConcurrent" type="number" optional>
  The most attempts of this harness that run at the same time, across the run. A whole number of at least 1.
</Property>

<Property name="startTimeout" type="Duration" optional>
  How long the session may take to become ready before the attempt is an infra error, after one retry. A duration, such as `3m`. Defaults to `90s`.
</Property>

<Property name="gateway" type="'direct' | 'vercel' | 'openrouter'" optional>
  The gateway this harness's model calls go through. It skips the config's `gateway` fallback, and the plan refuses a gateway that isn't listed or can't serve the harness. For more information about routing, see [Route models through a gateway](/agents/gateways).
</Property>

Each harness page covers the options and behavior that are specific to that harness, including its plugin support.
