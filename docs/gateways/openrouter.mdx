---
title: "openrouter gateway"
description: "Use the OpenRouter for an LLM model."
---

Using an OpenRouter gateway means that LLM calls will go through the OpenRouter, and requires that an OpenRouter API key is provided.

```ts
import { defineConfig } from 'reeval'
import { openrouter } from 'reeval/gateway'
import { claudeCode, codex, cursor, opencode } from 'reeval/harness'

export default defineConfig({
  gateway: [
    openrouter()
  ]
})
```

The environment variable `OPENROUTER_API_KEY` must be set to the API key for the OpenRouter.
