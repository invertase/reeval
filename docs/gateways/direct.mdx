---
title: "direct gateway"
description: "Use the direct provider for an LLM model."
---

Using a direct gateway means that LLM calls will go directly to the model providers API, and requires that an API key is provided for each.

```ts
import { defineConfig } from 'reeval'
import { direct, vercel } from 'reeval/gateway'
import { claudeCode, codex, cursor, opencode } from 'reeval/harness'

export default defineConfig({
  gateway: [
    direct()
  ]
})
```

This is the default reeval behaviour.
