---
title: "Fail a pull request"
description: "Fail a pull request when an evaluation regresses."
---

A pull request fails when an evaluation that passed on its base commit fails on its head. For the workflow file that sets this up, including the recording profile, the API key, the run, and the compare, see [CI](/evaluations/runs/ci). For a runnable project, see [`with-github-pr-gate`](https://github.com/invertase/reeval/tree/main/examples/with-github-pr-gate).

## Read the job result

The job summary holds the diff between the head and the base. A regressed evaluation lists the assertions whose outcomes changed:

```text
regressed        adds a LangGraph node
  base             20261020T230147Z_958e309_cursor-agent_aamj
  head             20261020T230148Z_958e309_cursor-agent_qghb
  graph compiles   pass → fail
    expected command to succeed, exit code 1
  state schema     not run
  +1 more passed
```

The job fails when the diff reports a regression. For the rule, see [CI](/evaluations/runs/ci). For the words the diff uses, see [Compare with past runs](/results/compare/past-runs#fail-on-a-regression).
