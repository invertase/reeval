---
title: "vertex gateway"
description: "Use the Google Vertex AI for an LLM model."
---

Using a Google Vertex AI Gateway means that LLM calls will go through the Google Vertex AI, and requires that a Google Vertex AI API key is provided.

```ts
import { defineConfig } from '{{ pkg }}'
import { vertex } from '{{ pkg }}/gateway'
import { claudeCode, codex, cursor, opencode } from '{{ pkg }}/harness'

export default defineConfig({
  gateway: [
    vertex({ project: 'my-project', location: 'us-central1' })
  ]
})
```
