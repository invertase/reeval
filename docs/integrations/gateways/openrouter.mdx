---
title: "openrouter gateway"
description: "Send model calls through OpenRouter on one key."
---

`openrouter()` sends the model calls of the harnesses it serves through OpenRouter, on one key. The egress gateway swaps the key in only on OpenRouter's model paths at `openrouter.ai`, so the key never enters the sandbox.

## `OPENROUTER_API_KEY`

`openrouter()` reads `OPENROUTER_API_KEY` from the environment or the `.env.local` file. A run exits with code 2 when the variable is unset and a planned harness or model takes `openrouter()`.

For more information about the variable, see [`OPENROUTER_API_KEY`](/reference/env-vars#openrouterapikey).

## `openrouter()`

`openrouter()` is exported from `{{ pkg }}/gateway`:

```ts title="reeval.config.ts"
import { defineConfig } from '{{ pkg }}'
import { direct, openrouter } from '{{ pkg }}/gateway'

export default defineConfig({
  gateway: [openrouter(), direct()],
})
```

<Property name="fallbacks" type="boolean" optional>
  Lets reeval's own calls, the judge, analysis, questions, and captures, fail over to another upstream provider when the first one fails. Defaults to `false`. The harnesses' calls take OpenRouter's own routing either way.
</Property>

A harness `openrouter()` cannot serve takes the next gateway in the list. Each call records the upstream provider that served it, on the attempt's `upstreams` and the judgment's `upstream`.

For more information about combining gateways, see [Gateways](/agents/gateways).

## Harnesses

| Serves | Falls through |
| :--- | :--- |
| Claude Code, Codex, Goose, OpenCode, Grok Build | Cursor, Antigravity, fx, pi |

Cursor's agent calls only Cursor's API, Antigravity's CLI calls only Google's, and fx reaches models only on the Vercel AI Gateway or OpenAI's API. reeval runs pi on its Gemini key. A Claude Code, Goose, OpenCode, or Grok Build harness with `effort` set also takes the next gateway.

On `openrouter()`, a judge must be a decision model that OpenRouter answers on its Decisions API, such as `typesafe/jev-1.14`, and each call to any other judge model fails.
