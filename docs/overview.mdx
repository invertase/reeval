## Introduction

**reeval** is an open-source evaluation runner built for developer tools, including SDKs, CLIs, MCP servers, skills, and documentation.

It runs coding agents inside isolated sandboxes, then grades their output using assertions and LLM judgments. Run identical prompted tasks across a baseline and a variant (your change) to compare whether it improves or regresses pass rates, tokens, and time.

The evaluation is code, committed alongside the tool, skill, or doc you are changing. The result is reproducible evidence you can share in pull requests, docs, or release notes.

Ask a coding agent to set reeval up with the setup skill:

```bash
npx skills add https://github.com/invertase/reeval --skill setup
```

To set it up by hand, install reeval:

```bash
npm install -D reeval
```

## How reeval works

Agents, environments, and attempts multiply into sandboxes: each attempt of each agent in each environment runs in its own sandbox. Grading reads the workspace in each sandbox. reeval then measures the results, compares them with the baseline and with past runs, and analyzes them.

## Run an evaluation

The following evaluation asks an agent for a page in Anthropic's brand. The baseline runs without Anthropic's `brand-guidelines` skill, and the variant runs with it. The environments go in one file:

```ts title="evals/environments.ts"
import { defineEnvironment } from 'reeval'

export const page = defineEnvironment('page', ({ directory }) => ({
  files: directory('./project'),
}))

export const withSkill = page.extendEnvironment(
  'brand-guidelines',
  ({ skill }) => ({
    skills: [
      skill.git('github:anthropics/skills', {
        ref: 'dbd4588f9e1033efb41dad4bef2f7947c8993d44',
        path: 'skills',
        only: ['brand-guidelines'],
      }),
    ],
  }),
)
```

The evaluation goes in its own file:

```ts title="evals/brand.eval.ts"
import { evaluate, expect } from 'reeval'
import { page, withSkill } from './environments.ts'

evaluate(
  "styles the page in Anthropic's brand",
  {
    environment: page,
    compare: { variants: [withSkill] },
    runs: 4,
    gate: { passRate: 0.75 },
  },
  async (c) => {
    await c.send(
      "Give index.html Anthropic's look: write styles.css with Anthropic's " +
        'brand colors and fonts, and link it from index.html.',
    )

    await expect(c, 'links styles.css').toHaveFile(
      'index.html',
      /href="styles\.css"/,
    )
    await expect(c, 'brand orange').toHaveFile('styles.css', /#d97757/i)
    await expect(c, 'brand fonts').toHaveFile(
      'styles.css',
      /Poppins[\s\S]*Lora|Lora[\s\S]*Poppins/,
    )
  },
)
```

The prompt never names the color or the fonts, so those assertions pass only when the agent knows them. `reeval run` prints the outcome for each side:

```text
pass             styles the page in Anthropic's brand
  arm               pass
  page              0 of 4
  brand-guidelines  4 of 4  helped
  check             page    brand-guidelines
  brand orange      0 of 4  4 of 4
    expected styles.css to match /#d97757/i
  brand fonts       0 of 4  4 of 4
    expected styles.css to match /Poppins[\s\S]*Lora|Lora[\s\S]*Poppins/
  +1 more passed
```

The variant passed in 4 of 4 attempts and the baseline in none, so the skill `helped`.
