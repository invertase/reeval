description: "Let your agent call tools exposed by MCP servers."
---

You set `mcp` on an environment to give the agent servers it can call during an attempt. For more information about the history server `reeval mcp` serves, see [History MCP server reference](/reference/mcp-tools).

## Add a stdio server

`mcp.stdio` runs a command in the sandbox. The command must use MCP over stdin and stdout. The key in `mcp` is the server name.

In the `evals/environments.ts` file, copy the server's script into the workspace and add it as the `releases` server:

```ts title="evals/environments.ts"
import { defineEnvironment } from '{{ pkg }}'

export const app = defineEnvironment(
  'acme-cli',
  ({ directory, file, mcp }) => ({
    files: {
      ...directory('./project'),
      'mcp/releases.mjs': file('./mcp/releases.mjs'),
    },
    mcp: { releases: mcp.stdio('node', ['mcp/releases.mjs']) },
  }),
)
```

The command runs in the workspace, so `mcp/releases.mjs` is the copied script. A server from npm runs the same way, such as `mcp.stdio('npx', ['-y', '<package>'])`.

For more information about connecting a server by URL with `mcp.http` or `mcp.sse`, see [Environment helpers](/reference/environment#mcpstdio).

## Check the agent called the server

`toHaveCalledMcp` passes when the transcript has a call named `mcp__<server>__<tool>`. Pass the server name, the tool name the server advertises, and `c` or the turn that `c.send` returns.

In the `evals/releases.eval.ts` file, send the task and check the call:

```ts title="evals/releases.eval.ts"
evaluate('bumps to the latest release', { environment: app }, async (c) => {
  const turn = await c.send(
    "Set package.json's version to the latest acme-cli release. " +
      "The releases MCP server's latest_version tool knows it.",
  )

  expect(turn).toHaveCalledMcp('releases', 'latest_version')
  await expect(turn).toHaveFile('package.json', /"version": "2\.4\.0"/)
})
```

The attempt's transcript names that call `mcp__releases__latest_version`:

```text
{"turn":0,…,"type":"tool","toolCallId":"call_1","tool":"mcp__releases__latest_version","input":{},"output":"acme-cli 2.4.0","ok":true,"durationMs":178}
```

To match the tool input, pass a string, a regular expression, or an object as the third argument. For more information about the arguments, see [the `toHaveCalledMcp` matcher](/reference/matchers#tohavecalledmcp). For a runnable project, see [`with-mcp`](https://github.com/invertase/reeval/tree/main/examples/with-mcp).

## Troubleshooting

Match the message to a fix:

| Symptom | Check | Next action |
|---|---|---|
| `MCP server releases didn't answer initialize within 60s` | The stdio command never answered `initialize`. The attempt stops. | Run the command in the sandbox and read why it exits. |
| `MCP server releases took 4s to start.` | A stdio server took at least 2 seconds to answer `initialize`. | Install the package in the image. For more information about install layers, see [Add install layers](/integrations/sandboxes/toolchains#add-install-layers). |
| `expected MCP calls matching releases/latest_version, got none` | The transcript has no matching MCP call. | Pass the server name from `mcp` and the tool name the server advertises. |
