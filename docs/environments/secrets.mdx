---
title: "Pass secrets"
description: "Pass environment variables and secrets so keys stay on the host."
---

The `env` field sets variables in the sandbox. reeval copies a string in as its value. Pass an API key with `secret` so the key stays on the host.

## Keep API keys on the host

reeval puts a placeholder in the sandbox, `reeval_secret_` followed by 32 characters. The egress gateway swaps in the real key on an HTTPS request to a host you name, and puts the placeholder back in that host's response.

Put the key in the `.env.local` file next to the `reeval.config.ts` file:

```bash title=".env.local"
SDK_API_KEY=replace-with-your-key
```

A variable exported in the shell takes precedence over the `.env.local` file, and that file takes precedence over the `.env` file.

For more information about which hosts the sandbox can reach, see [Egress](/environments/egress).

## Set an environment variable

In the `evals/secrets.eval.ts` file, define an environment with a plain variable and run an evaluation in it:

```ts title="evals/secrets.eval.ts"
import { defineEnvironment, evaluate, expect } from '{{ pkg }}'

const chatbot = defineEnvironment('chatbot', {
  env: { LOG_LEVEL: 'info' },
})

evaluate('reads the log level', { environment: chatbot }, async (c) => {
  await c.send('Write the value of LOG_LEVEL to level.txt.')
  await expect(c, 'writes the level').toHaveFile('level.txt', /info/)
})
```

A child made with `extendEnvironment()` replaces a shared name. An `env` key on the config, a profile, a group, or an evaluation merges in first, and the environment's value takes precedence. The `defineConfig()` callback receives `secret`.

A name containing `KEY`, `TOKEN`, `SECRET`, `PASSWORD`, or `CREDENTIAL` must be a `secret`. reeval refuses a literal string.

## Pass a secret

In the `evals/secrets.eval.ts` file, take `secret` from the helpers and read the host variable with `secret.fromEnv()`:

```ts title="evals/secrets.eval.ts"
const chatbot = defineEnvironment('chatbot', ({ secret }) => ({
  env: {
    // ...
    SDK_API_KEY: secret.fromEnv('SDK_API_KEY'),
  },
}))
```

reeval records the name and redacts the value in everything it writes. For more information about the `secret()` shorthand and the options that change who receives a secret, see [`secret.fromEnv`](/reference/environment#secretfromenv). For more information about secrets in MCP server headers, see [MCP servers](/environments/mcp).

## Broker a secret to a host

Broker the key, refuse unbrokered secrets, and check the plan in this order.

1. In the `evals/secrets.eval.ts` file, name the hosts the key is sent to:

   ```ts title="evals/secrets.eval.ts"
       SDK_API_KEY: secret.fromEnv('SDK_API_KEY', {
         hosts: ['api.example.com'],
       }),
   ```

   Provider API presets are `secret.hosts.gemini`, `secret.hosts.openai`, `secret.hosts.anthropic`, and `secret.hosts.github`. A pattern such as `*.example.com` matches subdomains. The `in` option accepts an array containing `'header'`, `'query'`, or `'body'`, such as `in: ['header', 'body']`; it defaults to header substitution.

2. In the `reeval.config.ts` file, refuse a secret without `hosts`, which the sandbox would hold as the real key:

   ```ts title="reeval.config.ts"
     secrets: { unbrokered: 'error' },
   ```

3. Print the plan:

   ```bash
   npx reeval run --dry-run
   ```

   The notes name each brokered variable and its hosts:

   ```text
   brokered: SDK_API_KEY → api.example.com
   ```

## Troubleshooting

Use the row whose symptom matches the message.

| Symptom | Check | Next action |
| :--- | :--- | :--- |
| `isn't set. Set it in the environment or .env.local.` | The variable name | Set it in the `.env.local` file, or export it in the shell |
| `is a literal string. Pass secrets with secret.fromEnv()` | That `env` entry | Pass `secret.fromEnv()` |
| `is in the sandbox as its real value` | The plan warning | Add `hosts` |
| `isn't brokered, and secrets.unbrokered is 'error'` | `secrets` in the `reeval.config.ts` file | Add `hosts`. The run exits with code 2 |
| `has whitespace or a line break in it` | A key copied from a wrapped terminal line | Set the value as one line |
