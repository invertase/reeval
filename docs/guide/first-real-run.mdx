The quickstart ran against a fake agent. Here you run the same kind of eval on a real one: Cursor does the task in a fresh Docker container, and a real judge grades it.

**Before you begin:** Node {{ node }} or later, a running Docker, a Cursor API key and a key for your judge.

## Point the config at Cursor

```ts title="es.config.ts"
import { defineConfig } from '{{ pkg }}'
import { cursor } from '{{ pkg }}/harness'
import { docker } from '{{ pkg }}/sandbox'

export default defineConfig({
  include: ['evals/**/*.es.ts'],
  harness: cursor({ model: 'composer-2.5' }),
  sandbox: docker(),
  judge: { model: 'google/gemini-3.8-flash', threshold: 0.8 },
  timeout: '15m',
})
```

The [harness](/reference/harness/cursor) is the agent, and the [sandbox](/reference/sandbox/docker) is where it runs. `docker()` with no options uses ES's own image: Node 22, git and the Cursor CLI.

## Write the evals

These are the `greet` evals from `examples/hello`, which the rest of the Guide builds on:

```ts title="evals/hello.es.ts"
import { evaluate, expect, group } from '{{ pkg }}'

const callGreetWithNoArgs = `node -e "import('./greet.js').then((m) => {
  const greet = m.greet ?? m.default?.greet ?? m.default
  process.exit(greet() === 'Hello, world!' ? 0 : 1)
})"`

group('greet module', () => {
  evaluate('creates a tested greet module', async (t) => {
    const turn = await t.send(
      'Create greet.js exporting greet(name) that returns "Hello, <name>!", ' +
        'and greet.test.js that tests it with node:test. No dependencies.',
    )

    await expect(turn).toHaveFile('greet.js')
    await expect(t.exec('node --test')).toSucceed()
    expect(
      await t.judge(
        "Does the agent's final message accurately describe what it changed?",
      ),
    ).toPass()
  })

  evaluate('adds a default name in a follow-up turn', async (t) => {
    await t.send(
      'Create greet.js exporting greet(name) that returns "Hello, <name>!". ' +
        'No dependencies.',
    )
    await t.send(
      'Make name default to "world" ' +
        'when greet() is called without arguments.',
    )

    await expect(t.exec(callGreetWithNoArgs)).toSucceed()
    expect(
      await t.judge(
        'Did the agent add the default without breaking greet(name)?',
      ),
    ).toPass()
  })
})
```

[Evals and checks](/guide/writing-evals) explains each line.

## Build the sandbox image

```bash
npx es image build
```

```text

```

ES bakes the agent's CLI into its image once, tagged with the harness adapter's version (`evalsuite-sandbox:cursor-1.0.37`). Rebuild after you upgrade ES.

## Add your keys

```bash title=".env.local"
CURSOR_API_KEY=...
GOOGLE_GENERATIVE_AI_API_KEY=...
```

`es run` reads `.env.local` and `.env` from the current directory. The judge key depends on the judge model: `google/*` models use `GOOGLE_GENERATIVE_AI_API_KEY`, and `typesafe-ai/jev-1.13.0` uses `TYPESAFE_AI_API_KEY`.

<Warning>
  Run `es` from the directory that holds `.env.local`, usually your project root. A key in another directory isn't read.
</Warning>

## Your key stays on the host

`CURSOR_API_KEY` never enters the container. The agent sees a placeholder, and ES's egress gateway swaps in the real key only on the request that exchanges it with Cursor. A check that prints `env` in the sandbox finds `aisdkhc_…`, not your key. [Credential brokering](/concepts/credential-brokering) shows how.

`es run -v` says so for every attempt:

```text
[agent#1 cursor]  17:06:35 broker    CURSOR_API_KEY stays on the host · the gateway swaps it in on POST api2.cursor.sh/auth/exchange_user_api_key
```

## Find the run

```text
.es/runs/
  20260926T170537Z_bd6205e_ada-lovelace_b50g.json    the record
  20260926T170537Z_bd6205e_ada-lovelace_b50g/
    summary.md                                     the run as Markdown
    <eval>/<cell>/1/                               transcript, diff, checks, judge input
```

Every `es run` writes a scratch run under `.es/runs/`. The name is the UTC start time, the commit, the author and a random suffix. [History](/guide/history) shows how to keep runs in git.

## Ignore local files

```text title=".gitignore"
.es/
.env*
```

`.es/` holds scratch runs, caches and debug data. `.env*` holds your keys.
