The quickstart ran against a fake agent. Here you run the same kind of eval on a real one: Cursor does the task in a fresh Docker container, and a real judge grades it.

**Before you begin:** Node {{ node }} or later, a running Docker, a Cursor API key and a key for your judge.

<Info>
  reeval's sandboxes are Linux containers. On Windows, use Docker Desktop on the WSL 2 backend, running Linux containers (not Windows containers). `reeval doctor` checks both and names the fix.
</Info>

## Point the config at Cursor

```ts title="reeval.config.ts"
import { defineConfig } from '{{ pkg }}'
import { cursor } from '{{ pkg }}/harness'
import { docker } from '{{ pkg }}/sandbox'

export default defineConfig({
  include: ['evals/**/*.eval.ts'],
  harness: cursor({ model: 'composer-2.5' }),
  sandbox: docker(),
  judge: { model: 'google/gemini-3.8-flash', threshold: 0.8 },
  timeout: '15m',
})
```

The [harness](/reference/harness/cursor) is the agent, and the [sandbox](/reference/sandbox/docker) is where it runs. `docker()`, the default, uses reeval's own image: Node 22, git and Cursor's agent, which reeval drives through the Cursor TypeScript SDK. `model` is required.

## Write the evals

These are the `greet` evals from `examples/hello`, which the rest of the Guide builds on:

```ts title="evals/hello.eval.ts"
import { evaluate, expect, group } from '{{ pkg }}'

const callGreetWithNoArgs = `node -e "import('./greet.js').then((m) => {
  const greet = m.greet ?? m.default?.greet ?? m.default
  process.exit(greet() === 'Hello, world!' ? 0 : 1)
})"`

group('greet module', () => {
  evaluate('creates a tested greet module', async (c) => {
    const turn = await c.send(
      'Create greet.js exporting greet(name) that returns "Hello, <name>!", ' +
        'and greet.test.js that tests it with node:test. No dependencies.',
    )

    await expect(turn).toHaveFile('greet.js')
    await expect(c.exec('node --test')).toSucceed()
    expect(
      await c.judge(
        "Does the agent's final message accurately describe what it changed?",
      ),
    ).toPass()
  })

  evaluate('adds a default name in a follow-up turn', async (c) => {
    await c.send(
      'Create greet.js exporting greet(name) that returns "Hello, <name>!". ' +
        'No dependencies.',
    )
    await c.send(
      'Make name default to "world" ' +
        'when greet() is called without arguments.',
    )

    await expect(c.exec(callGreetWithNoArgs)).toSucceed()
    expect(
      await c.judge(
        'Did the agent add the default without breaking greet(name)?',
      ),
    ).toPass()
  })
})
```

[Evals and checks](/guide/writing-evals) explains each line.

reeval bakes the agent into its image once, tagged with the harness adapter's version (`reeval-sandbox:cursor-0.1.5`). Rebuild after you upgrade reeval.

## Add your keys

```bash title=".env.local"
CURSOR_API_KEY=...
GOOGLE_GENERATIVE_AI_API_KEY=...
```

`reeval run` reads `.env.local` and `.env` from the directory that holds `reeval.config.ts`, wherever you run it from. The judge key depends on the judge model: `google/*` models use `GOOGLE_GENERATIVE_AI_API_KEY`, and `typesafe-ai/jev-1.14.0` uses `TYPESAFE_AI_API_KEY`.

<Warning>
  Put `.env.local` next to `reeval.config.ts`. A key in another directory, the current one included, isn't read.
</Warning>

## Your key stays on the host

```text
[agent#1 cursor]  17:40:47 broker    CURSOR_API_KEY stays on the host · the gateway swaps it in on POST api2.cursor.sh/auth/exchange_user_api_key
```

`reeval run -v` prints that line for every attempt. `CURSOR_API_KEY` never enters the container: the agent sees a placeholder, and reeval's egress gateway swaps in the real key only on the request that exchanges it with Cursor.

A check that prints `env` in the sandbox finds `aisdkhc_…`, not your key. [Credential brokering](/concepts/credential-brokering) shows how.

`hello` is a filter: it matches the file `evals/hello.eval.ts`. Each eval ran as one [attempt](/concepts/attempt-lifecycle) in its own container, side by side. With `--log-order grouped`, each attempt prints as one block when it ends: the sandbox, each turn, each check and each judge verdict (`pass 1.00 (≥ 0.8)`: its score against the threshold).

Then comes a block per eval: a pass prints its name only. The line under the blocks has the run's time and the tokens Cursor reported (input, the cached part and output); reeval records them per turn and per attempt but prices no models, so there's no cost. Last are the tally and a hint: with [`analysis.model`](/guide/analysis) set, a model answers what each eval asks.

## Find the run

```text
.reeval/runs/
  20260926T174005Z_b010670_ada-lovelace_xdb9.json    the record
  20260926T174005Z_b010670_ada-lovelace_xdb9/
    summary.md                                     the run as Markdown
    <eval>/<cell>/1/                               transcript, diff, checks, judge input
```

Every `reeval run` writes a scratch run under `.reeval/runs/`. The name is the UTC start time, the commit, the author and a random suffix; the plan line prints it, and `.reeval/current` points at it so `reeval run --resume` can continue after a crash. [History](/guide/history) shows how to keep runs in git.

## Run from any directory

```bash
cd src/lib
npx reeval run --dry-run
```

```text
plan  config ../../reeval.config.ts · …
```

`reeval` uses the nearest `reeval.config.ts` in the current directory or above, as Vitest and ESLint find their configs, and the plan line names it. Every path is the config's: the evals, `.env.local` and `.reeval/runs/` stay at the project root, for every command. A nested project with its own config uses that one; [Loading](/reference/config#loading) has the rules.

## Ignore local files

```text title=".gitignore"
.reeval/
.env*
```

`.reeval/` holds scratch runs, caches and debug data. `.env*` holds your keys.

A real agent passed your evals in Docker, and your key never left the host.
