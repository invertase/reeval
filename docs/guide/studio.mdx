---
title: The studio
description: Browse runs, cells, transcripts and diffs in a local web app, and publish it as a static site.
---

The studio is a web app over your history: every run, every eval across runs, and every attempt's transcript, diff, checks and judge input.

```bash
npx es studio
```

```text
es studio · scratch-guide · evals/.history/
  http://127.0.0.1:4984/?token=…
Ctrl-C to stop.
```

Open the printed URL. New runs appear as they're recorded, and unrecorded runs from `.es/runs/` show too, labelled scratch (`--no-scratch` hides them). `--open` opens the browser for you.

## Browse runs

<Image src="/assets/studio/runs.png" alt="The studio's runs list, with commit, branch, pass counts, duration and drift badges" width={800} />

The runs list shows each run's commit, branch, author (or CI), pass counts and duration. A `drift` badge means a cell's fingerprint changed since the last run that had it: its eval, image, agent CLI or environment.

## Read a run

<Image src="/assets/studio/run-cells-lift.png" alt="A run page with a cells table showing the control at 0% and the variant at 100%, with its lift" width={800} />

A run's page is its eval tree, with each cell's pass rate, role, lift and effort. This is the cross-agent run from [Harnesses](/guide/harnesses). A run you've analysed with `es analyze` also has an Analysis tab; [Analysis](/guide/analysis) shows how.

## Follow one eval

<Image src="/assets/studio/eval-history.png" alt="One eval across runs, with pass rates and fingerprint change marks" width={800} />

An eval's page lists it across runs, with a mark where its fingerprint changed. The compare page diffs two runs, as `es compare` does; [History](/guide/history) shows both.

## Keep it private

```bash
npx es studio --port 5000 --host 127.0.0.1
```

The studio listens on `127.0.0.1:4984` (or the next free port) and needs the session token in the URL it prints, so other local users and web pages can't read your transcripts. `--no-token` turns the check off, with a warning.

## Publish a static build

```bash
npx es studio build --out site
```

```text
built site/: 1 run, 12 files, 673 KB (records, transcripts, diffs, logs and judge inputs)
Serve it from any static host. Anyone who can open it can read every included file.
```

`es studio build` writes the same app as a static folder, for GitHub Pages, Netlify, Cloudflare Pages or any static host. It includes recorded runs only (`--scratch` adds the rest), and never debug data.

<Warning>
  A build includes transcripts, diffs and logs. Host it where your repo's readers are, or pass `--no-artifacts` to publish only the records.
</Warning>
