---
title: Multi-turn evals
description: Send follow-up turns in one agent session, and check each turn's status, diff and transcript.
---

Real work takes more than one prompt. Call `t.send` again and the agent carries on in the same session, with the same workspace. This is the second `greet` eval:

```ts title="evals/hello.es.ts"
evaluate('adds a default name in a follow-up turn', async (t) => {
  await t.send(
    'Create greet.js exporting greet(name) that returns "Hello, <name>!". ' +
      'No dependencies.',
  )
  await t.send(
    'Make name default to "world" ' +
      'when greet() is called without arguments.',
  )

  await expect(t.exec(callGreetWithNoArgs)).toSucceed()
  expect(
    await t.judge(
      'Did the agent add the default without breaking greet(name)?',
    ),
  ).toPass()
})
```

The checks run after both turns, and the judge grades the latest one.

## Keep each turn

```ts title="evals/guide.es.ts"
evaluate('checks turns', async (t) => {
  const first = await t.send(
    'Create greet.js exporting greet(name) that returns "Hello, <name>!".',
  )
  const second = await t.send('Make name default to "world".')
  // …
  expect(t.turns).toHaveLength(2)
})
```

`t.send` returns a `Turn` for that turn, and `t.turns` lists every turn so far, oldest first. A turn doesn't change after it resolves, so you can check the first one after the second has run.

## Check a turn's status

```ts
expect(second.status).toBe('completed')
```

`status` is `completed`, `aborted` or `error`. A turn that errors doesn't throw, so check the status when the rest of the eval depends on the agent finishing.

## Check what changed

```ts
const changed = second.diff.files.map((file) => file.path)
expect(changed).toContain('greet.js')
expect(changed).not.toContain('package-lock.json')
```

`turn.diff` is every change since the eval started, as of the end of that turn: `files` (each with `added`, `modified` or `deleted`) and the unified `patch`. Files the environment wrote before the agent started aren't in it, so the diff is only the agent's work.

## Read the transcript

```ts
const edits = second.transcript.filter((e) => e.type === 'file-edit')
expect(edits.length).toBeGreaterThan(0)
```

`turn.transcript` is that turn's events, in order: `prompt`, `reasoning`, `text`, `tool`, `file-edit`, `web-search`, `web-fetch`, `error` and `turn-end`. Use it to check how the agent worked: which tools it called, whether it searched the web, how many files it touched. [Transcripts](/reference/transcript) lists every field.

## Judge an earlier turn

```ts
const created = await t.judge('Does greet.js export greet(name)?', {
  on: first,
})
expect(created).toPass()
```

`t.judge` grades the latest turn unless you pass `on`. `on: turn` grades an earlier turn, and `on: value` grades any value, such as a command's output.

<Info>
  Checks and `t.exec` see the workspace as it is now, after every turn. To check the state between turns, run the check before the next `t.send`.
</Info>
