## `goose()`

`goose()` is the Goose harness factory. For more information about supported sandboxes, see [Sandboxes](/sandboxes).

`goose()` is exported from `{{ pkg }}/harness`. The following configuration passes it as the `harness` option:

```ts title="reeval.config.ts"
import { defineConfig } from '{{ pkg }}'
import { goose } from '{{ pkg }}/harness'

export default defineConfig({
  harness: goose({
    model: 'gemini-3.8-flash',
    effort: 'high',
  }),
})
```

`model` is required. The other fields are optional.

<Property name="model" type="string" required>
  A model id with no provider prefix, run on Goose's `google` provider. The value uses letters, digits, `_`, `.`, and `-`. reeval refuses any other `model` at plan time with exit code 2.
</Property>

<Property name="effort" type="string" optional>
  Reasoning effort passed as `GOOSE_THINKING_EFFORT`, such as `off`, `low`, `medium`, `high`, or `max`.
</Property>

<Property name="id" type="string" optional>
  Cell id. Defaults to `goose:<model>`, or `goose:<model>[effort=<value>]` when `effort` is set. The id uses letters, digits, and `._:@+-=[]`.
</Property>

<Property name="maxConcurrent" type="number" optional>
  The most Goose attempts that run at the same time, across the run. A whole number of at least 1.
</Property>

<Property name="startTimeout" type="Duration" optional>
  How long the session may take to become ready before the attempt is an infra error, after one retry. A duration, such as `3m`. Defaults to `90s`.
</Property>

For more information about choosing a harness, see [Choose a harness](/harnesses).

For more information about model ids, effort values, and served models, see [Models and providers for each harness](/harnesses/models).

## `GOOGLE_GENERATIVE_AI_API_KEY`

`goose()` reads `GOOGLE_GENERATIVE_AI_API_KEY` from the host. Goose reads that value as `GOOGLE_API_KEY`. The gateway brokers the key in the `x-goog-api-key` header on `POST /v1beta/models/<model>:streamGenerateContent` and `GET /v1beta/models` at `generativelanguage.googleapis.com`.

A missing `GOOGLE_GENERATIVE_AI_API_KEY` stops the run with exit code 2 before any attempt starts. When the API rejects the key, the attempt fails and the message names `GOOGLE_GENERATIVE_AI_API_KEY`.

For more information about keeping API keys on the host, see [Keep API keys on the host](/environments/secrets#keep-api-keys-on-the-host).

For more information about the variable, see [`GOOGLE_GENERATIVE_AI_API_KEY`](/reference/env-vars#googlegenerativeaiapikey).

Goose requests `models.dev` in every session to refresh its model catalogue, and no setting turns that request off. A restricted egress policy refuses `models.dev` and records it on `egress.expectedBlocked`.

For more information about blocked requests, see [Read blocked requests](/environments/egress#read-blocked-requests).

## `rules`

The Goose harness reads rules from the `AGENTS.md` file in the workspace.

For more information about writing rules, see [Add project rules](/environments/rules).

## `skills`

The Goose harness reads skills from the `.goose/skills` directory, the `.agents/skills` directory, and the `.claude/skills` directory in the workspace. Home skills are in the `.config/goose/skills` directory under the private home directory `~/.ai-sdk-harness/.harness-bootstrap/goose/implementation/home`.

For more information about placing skills, see [Give the agent skills](/environments/skills).

## `mcp`

The Goose harness accepts MCP servers on `stdio` and `http`. reeval refuses an `sse` server at plan time with exit code 2.

reeval writes each server into the `.config/goose/config.yaml` file under the private home directory `~/.ai-sdk-harness/.harness-bootstrap/goose/implementation/home`, as an enabled extension. A `stdio` server is `cmd`, `args`, and `envs`. An `http` server is `uri` and `headers`, with type `streamable_http`.

Goose keys each extension by dropping whitespace, replacing every character outside letters, digits, `_`, and `-` with `_`, and writing the name in lower case. Two servers that share that key are refused at plan time with exit code 2.

For more information about placing MCP servers, see [Connect MCP servers](/environments/mcp).

## `usage`

Goose leaves each turn's `usage` null. The adapter drops the session token count, which covers the last model call and would undercount the turn.

For more information about the token fields, see [`TokenUsage`](/reference/record#tokenusage).

## `servedModels`

Each turn's `model` is the model id from the last brokered `POST /v1beta/models/<model>:streamGenerateContent` request in the turn, or null when that turn made none. The attempt's `servedModels` lists every such id. The session stream names no model.

For more information about the attempt fields, see [`AttemptRecord`](/reference/record#attemptrecord).

## `web-search`

The Goose harness records no `web-search` events. Each turn's `unreported` list is empty.

For more information about the matcher, see [`toHaveSearched()`](/reference/matchers#tohavesearched).

## `web-fetch`

The Goose harness records no `web-fetch` events. Each turn's `unreported` list is empty.

For more information about the matcher, see [`toHaveFetched()`](/reference/matchers#tohavefetched).
