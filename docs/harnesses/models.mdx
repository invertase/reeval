title: "Set the agent's model"

Every harness factory takes a `model` and an optional `effort`. For more information about setting the model and effort on an evaluation, see [Set the model and effort](/harnesses#set-the-model-and-effort).

## `model`

`model` is the ID the harness's own CLI or SDK accepts. For more information about how each key stays on the host, see [Keep API keys on the host](/environments/secrets#keep-api-keys-on-the-host). For more information about every provider variable, see [Environment variables](/reference/env-vars).

reeval refuses a prefixed ID on a harness that takes a bare ID, or a bare ID on `opencode`, at plan time with exit code 2.

<Property name="cursor" type="string" required>
  A model ID `Cursor.models.list()` returns for the key. Key: `CURSOR_API_KEY`.
</Property>

<Property name="claudeCode" type="string" required>
  A model ID or alias the `claude` CLI accepts. Key: `ANTHROPIC_API_KEY`.
</Property>

<Property name="antigravity" type="string" required>
  A model slug `agy models` lists for the key, such as `<model>-medium`. The `-low`, `-medium`, and `-high` suffixes set effort in the slug. Key: `GEMINI_API_KEY`.
</Property>

<Property name="opencode" type="string" required>
  `<provider>/<model>`. The provider picks the key.
</Property>

For more information about supported providers, see [the `opencode` harness reference](/harnesses/opencode).

<Property name="goose" type="string" required>
  A model ID with no provider prefix. Key: `GOOGLE_GENERATIVE_AI_API_KEY`.
</Property>

<Property name="pi" type="string" required>
  A model ID with no provider prefix. Key: `GOOGLE_GENERATIVE_AI_API_KEY`.
</Property>

<Property name="codex" type="string" required>
  A model ID with no provider prefix. Key: `OPENAI_API_KEY`.
</Property>

<Property name="grokBuild" type="string" required>
  A model ID with no provider prefix. Key: `XAI_API_KEY`.
</Property>

## `effort`

`effort` is a reasoning-effort value the harness's own CLI or SDK takes. reeval passes it through, records it as `effort` on the cell, and names the cell `<kind>:<model>[effort=<value>]`. Only `claudeCode` checks the value at plan time.

<Property name="cursor" type="string" optional>
  A value of the effort parameter the harness's model catalog names for the model, `reasoning_effort` or `effort`. A model with no such parameter refuses `effort`. Fast is `params.fast`, not `effort`.
</Property>

<Property name="claudeCode" type="'low' | 'medium' | 'high' | 'xhigh' | 'max'" optional>
  The Agent SDK's `/effort` control. The harness UI displays `xhigh` as **Extra**. reeval refuses any other value at plan time.
</Property>

<Property name="antigravity" type="string" optional>
  The harness passes `low`, `medium`, `high`, or `max` as the `agy --effort` value. A slug suffix such as `-low` sets the same effort through `model`.
</Property>

<Property name="opencode" type="string" optional>
  A value the model's provider takes. reeval sets it as `options.thinking` on an `anthropic/` model and as `options.reasoningEffort` on every other provider.
</Property>

<Property name="goose" type="string" optional>
  The harness sets `GOOSE_THINKING_EFFORT` to `off`, `low`, `medium`, `high`, or `max`.
</Property>

<Property name="pi" type="string" optional>
  The harness passes `off`, `minimal`, `low`, `medium`, `high`, `xhigh`, or `max` to `--thinking`.
</Property>

<Property name="codex" type="string" optional>
  The harness sets `model_reasoning_effort` to `low`, `medium`, `high`, `xhigh`, `max`, or `ultra`.
</Property>

<Property name="grokBuild" type="string" optional>
  The harness sets `default_reasoning_effort` to `low`, `medium`, or `high` for a model that accepts it.
</Property>

## Route models through a gateway

A gateway serves your harness's and judge's model calls on one key. In the `reeval.config.ts` file, list `vercel()` in a profile's `gateway`:

```ts title="reeval.config.ts"
import { vercel } from '{{ pkg }}/gateway'
// ...
  vercel: {
    defaults: {
      harness: claudeCode({ model: 'claude-sonnet-5' }),
      sandbox: docker(),
    },
    judge: { model: 'typesafe-ai/jev-1.14.0' },
    gateway: [vercel()],
  },
```

The key is `AI_GATEWAY_API_KEY`. With `vercel()` alone in the list, a model Vercel AI Gateway can't serve stops the plan. Add `direct()` after it to fall back to the provider's own key. `openrouter()` routes through OpenRouter on `OPENROUTER_API_KEY`.

<Property name="gateway" type="'direct' | 'vercel' | 'openrouter'" optional>
  On a harness factory or `judge`, the one gateway its calls go through. It must be in the config's `gateway` list, and it skips the list's fallback.
</Property>

For a runnable project, see [`with-vercel-gateway`](https://github.com/invertase/reeval/tree/main/examples/with-vercel-gateway). For more information about the list, see [the `gateway` option](/reference/options#gateway).

## `turns[].model`

The record keeps the model that served each turn beside the configured `model`.

Each turn's `model` holds the corresponding served value. The `cursor` harness also includes parameters, such as `<model>[fast=false]`.

## `servedModels`

The attempt's `servedModels` is null for `cursor` and `claudeCode` because their API requests name no model.

The egress gateway reads the request URL into `servedModels` for `antigravity`, `goose`, `pi`, and `opencode` on a `google/` model. The harness sends `<model>-low` but the provider serves `<model>`.

The gateway reads the API response into `servedModels` for `codex`, `grokBuild`, and `opencode` on another provider.

## `servedEffort`

The `codex` response also names the resolved effort, such as `<model>[effort=medium]`. The attempt records it as `servedEffort`.

## `harnesses[].resolvedModels`

The run record's `harnesses[]` entries collect those served models as `resolvedModels`.

## `harnesses[].resolvedEffort`

The run record's `harnesses[]` entries collect those effort suffixes as `resolvedEffort`.

For more information about every run record field, see [Run record reference](/reference/record).
