---
title: Quickstart
description: Write and run your first eval in two minutes, with no API keys or Docker.
---

`reeval init` sets up a project with one eval and a real agent configured. The eval passes on reeval's fake agent first, which needs no keys, Docker or network.

**Before you begin:** Node {{ node }} or later, on Linux, macOS or Windows. On Windows the fake agent's commands run in [Git for Windows](https://git-scm.com/download/win)' `sh`.

<Steps>
  <Step title="Scaffold the project">
    ```bash
    npx {{ pkg }} init
    ```

    It asks which agent to configure. Press Enter for Cursor, or pick Claude Code, Antigravity, OpenCode, Goose, pi, Codex, fx or none:

    ```text
    reeval init · .
      create    reeval.config.ts       harness cursor:composer-2.5; profiles fake, pr, nightly
      create    evals/greet.eval.ts  one eval, passes on the fake agent
      create    .gitignore         .reeval/, .env*
      create    package.json       script eval, devDependency {{ pkg }}
    ```

    In a script, pass `--harness <name>` or `--yes`. It never overwrites a file that differs without `--force`: see [reeval init](/reference/cli/init).
  </Step>
  <Step title="Install">
    ```bash
    npm install
    ```

    npm, pnpm and Yarn (Plug'n'Play too) all work.
  </Step>
  <Step title="Read the eval">
    reeval finds `evals/**/*.eval.ts` by default.

    ```ts title="evals/greet.eval.ts"
    import { evaluate, expect } from '{{ pkg }}'

    const greetsAda = `node -e "import('./greet.js').then((m) =>
      process.exit(m.greet('Ada') === 'Hello, Ada!' ? 0 : 1))"`

    evaluate('creates greet.js', async (c) => {
      const turn = await c.send(
        'Create greet.js, an ES module exporting greet(name) that returns ' +
          '"Hello, <name>!". No dependencies.',
      )

      await expect(turn).toHaveFile('greet.js', /greet/)
      await expect(c.exec(greetsAda)).toSucceed()
    })
    ```

    `c.send` runs an agent turn. `c.exec` runs a command in the sandbox, and `toSucceed` checks its exit code.
  </Step>
  <Step title="Run it on the fake agent">
    The `fake` profile in `reeval.config.ts` swaps in a fake agent that writes `greet.js`, and a fake sandbox:

    ```bash
    npx reeval run --profile fake
    ```

    ```text
    plan  profile fake (--profile) · 1 eval · 1 cell · 1 attempt · ~1s serial
    reeval 0.0.1 · 1 eval file · harness fake · …
    [creates#1 fake] ▶ evals/greet.eval.ts › creates greet.js
    [creates#1 fake]  +0:00 turn 1 done 1ms · 0 tool calls, 1 file edit
    [creates#1 fake]  +0:00 $ node -e "import('./greet.js').then((m) =>…  exit 0 19ms
    [creates#1 fake] ✓ evals/greet.eval.ts › creates greet.js  56ms

    Summary
     evals/greet.eval.ts
       ✓ creates greet.js     56ms  1 turn

       Evals  1 passed (1)
    Duration  721ms
    ```
  </Step>
</Steps>

Your first eval passes. reeval saved the run under `.reeval/runs/`, which `reeval init` gitignored with `.env*`.

## Switch to a real agent

Without a profile, `reeval run` uses the agent you picked, in Docker. The eval doesn't change:

```ts title="reeval.config.ts"
export default defineConfig({
  include: ['evals/**/*.eval.ts'],
  harness: cursor({ model: 'composer-2.5' }), // needs CURSOR_API_KEY
  …
})
```

Check what will run first. `--dry-run` needs no keys or Docker:

```bash
npx reeval run --dry-run
```

```text
plan  1 eval · 1 cell · 1 attempt · ~3m 00s serial
eval                                  harnesses  variants  runs  attempts  notes
evals/greet.eval.ts › creates greet.js  1          —         1     1
```

Then build the sandbox image once, add your key, check the setup and run:

```bash
npx reeval image build
printf 'CURSOR_API_KEY=...\n' > .env.local
npx reeval doctor
npx reeval run
```

`reeval doctor` names anything missing, such as Docker not running or an unset key, with its fix.

<Warning>
  `reeval run` reads `.env.local` and `.env` from the config's directory, not the current one. Keep them next to `reeval.config.ts`.
</Warning>
