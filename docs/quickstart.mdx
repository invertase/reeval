reeval runs a coding agent in a sandbox and checks the outcome. Here you run the same harness as a baseline without the skill and a variant with the skill, then see whether the skill helped.

To have a coding agent follow these steps, use the [setup skill](https://github.com/invertase/reeval/tree/main/skills/setup).

## Before you begin

This example uses Docker for its sandbox. You need these:

| You need | For |
|---|---|
| Node {{ node }} or later | reeval's CLI |
| Docker or Podman | the sandbox |
| API keys for the agent harnesses | the harnesses |

For more information about other harnesses and their keys, see [Harnesses](/agents).

For more information about Podman or Docker on macOS or Windows, see [Sandboxes](/integrations/sandboxes).

## 1. Set up reeval

Install reeval in your project:

```bash
npm install -D {{ pkg }}
```

Create a project for your harness:

```bash
npx reeval init --harness claude-code
```

The command writes the `reeval.config.ts` and `evals/environments.ts` files and names the key your harness needs. Add the key to the `.env.local` file next to the `reeval.config.ts` file:

```bash title=".env.local"
ANTHROPIC_API_KEY=replace-with-your-key
```

Build the image your harness runs in:

```bash
npx reeval image build
```

For more information about image builds, see [Toolchains](/environments/toolchains).

Check Node, Docker, the image, and your key with the `reeval doctor` command:

```bash
npx reeval doctor
```

The command highlights any environment issues. When it finds none, the output ends with this line:

```text
No problems.
```

## 2. Write the evaluation

The baseline is an unstyled page. Create the `evals/project/index.html` file:

```html title="evals/project/index.html"
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>Release notes</title>
  </head>
  <body>
    <h1>Release notes</h1>
    <p>Version 2.0 is out, with faster builds and a new command line.</p>
  </body>
</html>
```

The variant adds Anthropic's `brand-guidelines` skill. Add the baseline and the variant to the end of the `evals/environments.ts` file:

```ts title="evals/environments.ts"
export const page = defineEnvironment('page', ({ directory }) => ({
  files: directory('./project'),
}))

export const withSkill = page.extendEnvironment(
  'brand-guidelines',
  ({ skill }) => ({
    skills: [
      skill.git('github:anthropics/skills', {
        ref: 'dbd4588f9e1033efb41dad4bef2f7947c8993d44',
        path: 'skills',
        only: ['brand-guidelines'],
      }),
    ],
  }),
)
```

The prompt doesn't name the brand's color or fonts, so those assertions pass only when the harness knows them. Create the evaluation:

```ts title="evals/brand.eval.ts"
import { evaluate, expect } from '{{ pkg }}'
import { page, withSkill } from './environments.ts'

evaluate(
  "styles the page in Anthropic's brand",
  {
    environment: page,
    compare: { variants: [withSkill] },
    runs: 4,
    gate: { passRate: 0.75 },
  },
  async (c) => {
    await c.send(
      "Give index.html Anthropic's look: write styles.css with Anthropic's " +
        'brand colors and fonts, and link it from index.html.',
    )

    await expect
      .soft(c, 'links styles.css')
      .toHaveFile('index.html', /href="styles\.css"/)
    await expect.soft(c, 'brand orange').toHaveFile('styles.css', /#d97757/i)
    await expect(c, 'brand fonts').toHaveFile(
      'styles.css',
      /Poppins[\s\S]*Lora|Lora[\s\S]*Poppins/,
    )
  },
)
```

The variant passes when at least 3 of its 4 attempts pass. For more information about why this evaluation uses four attempts, see [Statistics](/results/compare/statistics#four-attempt-minimum).

## 3. Run the comparison

Run the eight attempts:

```bash
npx reeval run brand
```

The run prints a block like this one:

```text
pass             styles the page in Anthropic's brand
  arm               pass
  page              0 of 4
  brand-guidelines  4 of 4  helped
  check             page    brand-guidelines
  brand orange      0 of 4  4 of 4
  brand fonts       0 of 4  4 of 4
  +1 more passed
```

The variant passed both brand assertions in 4 of 4 attempts and the baseline in 0 of 4, so the effect reads `helped`. Your counts can differ.
