---
title: "Ask questions across attempts"
description: "Ask a language model about the attempts after they end, without changing the outcome."
---

A question asks a language model about the attempts after they end. Assertions and judgments grade one attempt. A question with `across` reads across attempts and asks which side did better. Questions never change pass, fail, or the exit code.

For more information about grading one attempt, see [Assertions](/evals/checks) and [Judge agent work](/evals/judges).

## Ask which side did better

In the evaluation's options, add `questions`. This excerpt pairs Claude Code's attempts with Codex's in the same environment:

```ts title="with-compare-harness.eval.ts"
questions: [{ question: 'Which multiply() is easier to read?', across: 'harness' }],
```

`across: 'harness'` pairs agents in the same environment, and `across: 'environment'` pairs the baseline with each variant on the same agent. reeval asks about each pair of attempts that passed their assertions, in both orders, with the sides unlabeled. After the run, the block prints each side's wins as `won W of N`. For a runnable project, see [`with-compare-harness`](https://github.com/invertase/reeval/tree/main/examples/with-compare-harness).

## Ask each attempt on its own

Without `across`, reeval asks the question of each attempt on its own, once the attempt passes or fails. A question can be a string, or an object with `question` and `choices`, the answers it picks from with a short reason.

## Read the answers

`npx reeval query question_pairs` lists the wins, ties, and splits of each pairwise question. `attempt_answers` lists each attempt's answer. For more information about both views, see [Query views](/reference/query).
