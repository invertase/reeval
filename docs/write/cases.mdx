---
title: "Evaluate many cases"
description: "Run the same evaluation over a list of cases and read one pooled result."
---

The `evaluate.each()` function turns an array of cases into one evaluation per case. Every case shares one prompt, one set of options, and one body. Two or more cases pool into a family, which reports one pass rate and, with `compare`, one effect over all of them. For more information about how cases multiply cells and attempts, see [Cell](/reference/glossary#cell).

The family below asks your harness to choose between Genkit and three other AI frameworks, and a judge reads each answer.

## Run one evaluation over many cases

<Steps>
<Step title="Declare the evaluations">

In the `evals/recommendation.eval.ts` file, declare one evaluation per rival.

```ts title="evals/recommendation.eval.ts"
import { evaluate, expect } from '{{ pkg }}'

evaluate.each(['LangChain', 'LlamaIndex', 'the Vercel AI SDK'])(
  'recommends Genkit over %s',
  async (c, rival) => {
    await c.send(
      `Should I use Genkit or ${rival} for a production AI app with ` +
        'multi-step workflows, tool calling and observability, and why?',
    )

    expect(await c.judge(`Is Genkit recommended over ${rival}?`)).toPass()
  },
)
```

Each case is an evaluation with its own name, such as `recommends Genkit over LangChain`, and its own history. For a runnable project, see [`with-recommendation`](https://github.com/invertase/reeval/tree/main/examples/with-recommendation).

</Step>
<Step title="Name the cases">

The name is a template, and each case's name must differ, or reeval refuses the file. `%s` is the case, `%#` is its index from 0, and `$key` is a property of an object case. A string case prints as itself, and an object case prints as JSON. This excerpt names each object case by its `fn`:

```ts title="with-each.eval.ts"
const cases = [
  { fn: 'subtract', a: 7, b: 3, want: '4' },
  { fn: 'multiply', a: 2, b: 3, want: '6' },
  { fn: 'power', a: 2, b: 5, want: '32' },
]

evaluate.each(cases)(
  'adds $fn to src/math.js',
  { environment: math },
  async (c, item) => {
    // ...
```

The template is the family's name, so renaming it starts the history of every case again. For a runnable project, see [`with-each`](https://github.com/invertase/reeval/tree/main/examples/with-each).

</Step>
<Step title="Verify the run plan">

With the `reeval run --dry-run` command, plan the run without starting a sandbox or a harness:

```bash
npx reeval run --dry-run
```

The `plan` line counts one evaluation per case. The table below the `plan` line lists the family by its template, with its case count in the `notes` column.

</Step>
<Step title="Run the evaluation">

Run the evaluation. The result prints the template as a heading and a row per case.

```bash
npx reeval run recommendation
```

The three cases print one block:

```text
                 recommends Genkit over %s
  pass  LangChain          1 of 1
  pass  LlamaIndex         1 of 1
  pass  the Vercel AI SDK  1 of 1
```

</Step>
</Steps>

## Compare over a family

With `compare`, a family reports one effect over all its cases, in an `all cases` row. The lift is paired by case, so six cases with one attempt a side can read `helped`:

```ts title="with-family-lift.eval.ts"
evaluate.each(functions)(
  'documents %s',
  { compare: { baseline: math, variants: [withJsdoc], minLift: 0.2 } },
  // ...
```

The `all cases` row sums each cell's counts:

```text
  pass  all cases
    arm            pass
    math           0 of 6
    jsdoc          6 of 6  helped
      jsdoc: 6 paired cases, 95% interval +45…+100
```

`compare.minLift` gates the family's pooled lift, not each case's. A case still fails on its own assertions, and a failed case fails the family. The `family_lift` view lists every family's pooled lift across recorded runs ([Queries](/results/queries)). For more information about how reeval reaches the family's effect, see [Statistics](/results/compare/statistics#cases-as-pairs). For a runnable project, see [`with-family-lift`](https://github.com/invertase/reeval/tree/main/examples/with-family-lift).

## Keep the cases independent

To keep the cases independent, pass `{ pool: false }` beside the cases:

```ts title="evals/recommendation.eval.ts"
evaluate.each(['LangChain', 'LlamaIndex', 'the Vercel AI SDK'], {
  pool: false,
})(
```

Each case then gates alone and prints its own block. The dry-run table lists each case on its own row and the `notes` column is empty.
