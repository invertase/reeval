# Changelog

Every change adds one line to `CHANGELOG.md`, under `## Unreleased` at the top. Create the file
and the heading if they aren't there.

The line is `- <type>: <summary>`, where the type is `feat`, `fix` or `refactor`:

```md
## Unreleased

- feat: add divide(a, b) to src/math.js
```
