# Ledger brand

- Primary buttons are blue `#2563eb` with white text, no border and `0.5rem` rounded corners.
- Pad buttons `0.75rem 1.5rem`, with the body's font at `1rem`.
- Put the button's style in a class in the page's `<style>`, not inline.
