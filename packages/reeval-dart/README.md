# reeval for Dart

Write evals for coding agents in Dart. A real agent does each task in a sandbox, and
[reeval](https://reeval.ai) checks the result with assertions and an LLM judge.

```bash
dart pub add dev:reeval
dart run reeval run
```

`package:reeval` brings its own `reeval` command: it downloads the reeval binary of the same
version from the GitHub release, checks it against the release's `SHA256SUMS`, caches it and runs
it. `dart pub upgrade reeval` moves both.

## An eval

`evals/greet.eval.dart`:

```dart
import 'package:reeval/reeval.dart';

void main() {
  group('greet', harness: cursor(model: 'composer-2.5'), () {
    evaluate('writes a greeting', (c) async {
      final turn = await c.send('Write lib/greet.dart with greet(name).');
      await expectLater(turn, hasEdited('lib/greet.dart'));

      final result = await c.exec('dart test');
      expect(result.exitCode, 0, reason: 'the tests pass');
      await expectLater(c, hasFile('lib/greet.dart', RegExp(r'Hello, \$name')));

      final verdict = await c.judge('Is greet() idiomatic Dart?');
      expect(verdict, passes);
    }, timeout: const Duration(minutes: 5));
  });
}
```

It reads like a package:test file, and runs JIT under `dart run` in reeval's runner:

- `group` and `evaluate` declare evals in `main()`; `evaluate.each` declares one per case.
- `expect` checks here and now, with any package:matcher matcher. `await expectLater` runs
  reeval's own matchers (`hasFile`, `hasRun`, `hasEdited`, `succeeds`, …) in reeval.
- `assert`, `c.check(…)` and package:checks' `check(…)` count as checks too, each named by the
  code it checked.
- `print` and `stdout` go to the attempt's log; reeval's messages use private file descriptors.

## Running

reeval finds `evals/**/*.eval.dart` and starts `dart run reeval:runner` in your project, so evals
run against the `package:reeval` in your lockfile, which must be the binary's version.

| Variable | What it does |
|---|---|
| `REEVAL_DART` | The `dart` to start the runner with (the launcher sets it to the one running it) |
| `REEVAL_BINARY` | Run this reeval binary instead of downloading one |
| `REEVAL_VERSION` | Download this version instead of the package's |
| `REEVAL_DOWNLOAD` | A mirror of the release directory (`https://…` or `file://…`) |
| `REEVAL_OFFLINE` | `1`: never download; a binary that isn't cached exits 2, naming its path |

Binaries are cached in `$XDG_CACHE_HOME/reeval/bin/<version>/` (or `~/.cache/reeval`,
`~/Library/Caches/reeval`, `%LOCALAPPDATA%\reeval`).

## Developing

```bash
cd packages/reeval-dart
dart pub get
dart analyze
dart format .
dart test
```

The tests replay reeval's conformance goldens (`packages/reeval/test/conformance/`) through the
real runner. `lib/src/wire.g.dart` is generated by `packages/reeval/scripts/sdk-types.ts`.
